# 식당 소개 OVA 영상 만들기

식당 정보를 받아 1990년대 OVA 셀 애니메이션 풍의 30초 세로(9:16) 영상을 만든다.
그림, 움직임, 소리를 모두 코드로 만들기 때문에 식당 사진을 쓰지 않는다.

## 장면 구성 (30초)

| 시간 | 장면 |
|---|---|
| 0–7초 | 비 오는 밤 골목, 우산 쓴 행인, 지역 · 업종 자막 |
| 7–11초 | 간판과 등롱에 불이 켜지고 가게 이름이 뜬다 |
| 11–20초 | 대표 메뉴 최대 3개. 메뉴 이름으로 그릇을 고른다 (면·국물, 만두, 튀김, 덮밥, 음료, 그 외) |
| 20–25초 | 별점, 리뷰 수, 리뷰 한 줄 (데이터가 없으면 메뉴 장면이 길어진다) |
| 25–30초 | 가게 앞모습과 주소 · 영업시간 |

가게 이름에 따라 노렌 색과 주변 건물 배치가 바뀐다.

## 사용법

```bash
# 1. 식당 정보 가져오기 (SerpApi 구글 지도). 키는 환경 변수로만 넣는다.
export SERPAPI_KEY=...
python3 fetch_place.py "연남동 ○○라멘"                   # 후보가 여러 개면 목록이 나온다
python3 fetch_place.py "연남동 ○○라멘" --pick 1 --menu "돈코츠 라멘:11000,교자:6000"
#    → place.json, place.js 생성

# 2. MP4 만들기 (Node, Playwright, ffmpeg 필요. 한글 글꼴이 있어야 글자가 깨지지 않는다)
node render.js --place place.json --out 식당.mp4

# 예시 데이터로 바로 시험
node render.js --place sample_place.json --out sample.mp4
```

`scene.html`을 브라우저로 열면 `place.js`의 식당으로 소리와 함께 바로 재생된다.

## 파일

- `fetch_place.py`: SerpApi로 검색하고 고른 식당의 정보와 리뷰 한 줄을 `place.json` / `place.js`로 저장한다 (표준 라이브러리만 사용)
- `scene.html`: 장면 템플릿. 그림, 애니메이션, Web Audio 소리
- `render.js`: 프레임을 찍고 소리를 오프라인 렌더링해 ffmpeg로 MP4를 만든다
- `sample_place.json`: 가상의 식당 「달빛 라멘」 예시 데이터. 영상에 "예시 데이터" 표시가 붙는다

## 참고

- 메뉴는 구글 지도 결과에 없는 경우가 많아 `--menu`로 직접 넣는다.
- 검색 결과의 식당 사진은 저작권 때문에 쓰지 않는다.
- 공개 영상에 리뷰 문장을 넣을 때는 출처 표기("구글 지도 리뷰 기준")를 유지한다.
