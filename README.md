# 이클립스: 어웨이크닝 (ECLIPSE) — 리니지 라이크 웹 MMORPG

브라우저에서 바로 실행되는 리니지 스타일의 쿼터뷰 액션 RPG입니다. 빌드 과정이나 서버 없이 HTML5 Canvas와 순수 JavaScript로 동작합니다.

## 실행 방법

```bash
# 저장소 루트에서 정적 서버 실행
python3 -m http.server 8000
# 브라우저로 http://localhost:8000 접속
```

`index.html`을 더블클릭해서 열어도 실행됩니다. 진행 상황은 브라우저 `localStorage`에 자동 저장됩니다(10초마다, 창을 닫을 때).

## 주요 기능

| --- | --- |
| 클래스 | 기사(근접), 요정(원거리 활), 마법사(광역 마법). 클래스마다 스킬 6개 (Lv.15·Lv.30에 Q·E 스킬 해금) |
| 원소 이펙트 | 파티클 시스템으로 그립니다. 화염: 화염구와 화염 화살의 불꽃·불티·연기 꼬리, 폭발, 그을음 자국, 용암 바닥의 불기둥. 냉기: 얼음창과 서리 화살의 서리 꼬리, 솟아올랐다 부서지는 얼음 결정, 서리 바닥, 눈과 얼음 파편이 쏟아지는 블리자드. 냉기에 맞은 적은 푸르게 얼고 얼음에 갇히며, 화상은 몸에 불이 붙고 독은 거품이 올라옵니다. 메테오는 불꽃 꼬리와 파편, 번개는 스파크를 남깁니다. 밤에는 불과 폭발이 주변을 밝힙니다 |
| 스킬 트리 | **K** 키. 패스 오브 엑자일처럼 스킬마다 3단계, 단계마다 두 갈래 중 하나를 골라 스킬이 파생됩니다 (예: 파이어볼 → 거대 화염구 / 용암 지대). 레벨업마다 스킬 포인트 1, 단계 비용 1/2/3, 단계 개방 Lv.1/10/20. 불타는 바닥, 눈보라, 출혈, 독, 기절, 연쇄 번개, 파편, 흡혈 등의 효과가 있고 10,000 아데나로 초기화할 수 있습니다 |
| 월드 | 180×180 타일 맵. 라스카노 마을(안전 지역), 바람의 초원, 망자의 묘지, 오크 요새, 고요한 숲 |
| 몬스터 | 고블린, 늑대인간, 멧돼지 전사, 좀비, 해골 전사, 오크, 리자드맨, 트롤. 필드 보스는 뱀파이어 군주와 미노타우르스 킹 |
| AI 모드 | 자동 사냥: 적절한 사냥터로 이동한 뒤 몬스터를 찾아 공격하고 스킬을 사용합니다. A* 길찾기로 성벽, 목책, 호수, 건물을 돌아가고, 벽에 막히면 경로를 다시 계산하며, 그래도 닿지 않는 대상은 잠시 제외하고 다른 대상을 찾습니다 |
| 자동 물약 | HP 55% 이하가 되면 물약을 자동으로 사용합니다 |
| 초월 | 카드를 장착하면 외형이 바뀌고 능력치가 오릅니다. 등급은 일반/고급/희귀/영웅/전설이며 목록·합성·성장·보유 효과 탭이 있습니다 |
| 소환 | 메뉴 → 소환. 초월 / 무기 외형 / 펫 / 탈것 탭에서 1회 또는 11회 뽑기(희귀 이상 1개 확정). 슬롯머신처럼 돌다 멈추며, 희귀 이상은 파랑·빨강·노랑 번개와 함께 멈춥니다 |
| 합성 | 소환 화면의 합성 탭(또는 각 수집 화면의 합성 버튼). 같은 등급 중복 4개로 확률적으로 한 단계 위 등급을 얻고, 실패하면 같은 등급 하나를 얻습니다. 성공 확률 일반→고급 30%, 고급→희귀 25%, 희귀→영웅 20%, 영웅→전설 12%. 마지막 1개와 사용 중인 것은 소모되지 않습니다 |
| 장비 세트 | 희귀 2세트(은빛 기사단 Lv.22, 폭풍 추적자 Lv.27), 영웅 2세트(핏빛 군단 Lv.36, 심연의 파수꾼 Lv.44), 전설 1세트(천상의 심판 Lv.62). 세트마다 직업별 무기와 갑옷이 있고, 같은 세트의 무기+갑옷을 함께 착용하면 세트 효과(공격력 %, HP, 치명타 등)가 붙습니다. 장신구 추가: 맹공의 반지(희귀), 군주의 목걸이(영웅), 심판자의 인장(전설) |
| 수집 (확장) | 메뉴 → 수집. 40종, 탭: 무기 / 방어구·장신구 / 강화 / 세트 / 소모품 / 보스 전리품. **+숫자** 칸은 그 이상 강화한 장비로만 등록(예: +7 도전자, +9 신화의 경지). 무기 칸은 내 직업의 같은 등급 무기로 채움. 상단에 완성 효과 합계, '모두 등록'은 장비만 자동 등록(높은 강화 칸부터) |
| 장비/강화 | 무기·갑옷·장신구 장착. 무기 마법 주문서로 강화하며 안전 강화(무기 +6, 갑옷 +4)를 넘으면 실패 시 증발합니다 |
| 퀘스트 | 14단계 메인 퀘스트와 일일 토벌. 퀘스트 창을 클릭하면 탈것을 타고 길찾기로 해당 사냥터(또는 NPC)까지 이동한 뒤 AI 모드로 사냥합니다 (순간이동하지 않음) |
| 순간이동 모션 | 모든 순간이동은 마법진 시전, 빛기둥과 함께 사라짐, 도착지에서 나타남 순서로 연출됩니다. 다른 플레이어(봇)도 같은 모션을 씁니다 |

| 던전 (v1.1) | **이클립스 균열**: 일일 3회, 5분 제한, 4웨이브 + 보스. 몬스터 레벨이 캐릭터 레벨에 맞춰 조정되며 다이아, 주문서, 소환권을 보상으로 줍니다 |
| 낮/밤 (v1.1) | 8분 주기의 낮과 밤. 밤에는 횃불, 모닥불, 포탈, 캐릭터 주변만 밝습니다 |

## 조작

- **클릭**: 이동, 몬스터 공격, NPC 대화 (누르고 있으면 계속 이동)
- **WASD / 방향키**: 이동
- **1~4, Q, E**: 스킬 · **5~8**: 물약, 귀환 주문서 · **K**: 스킬 트리
- **Space**: 가까운 적 공격 · **G**: AI 모드 · **Shift**: 질주
- **I** 인벤토리 · **K** 스킬 · **U** 상점 · **C** 캐릭터 · **J** 퀘스트 · **Y** 초월 · **P** 시즌 패스 · **O** 보스 정보 · **T** 순간이동 · **B** 마을 귀환 · **M** 지도 · **Tab** 전체 메뉴
- **Enter**: 채팅 · **마우스 휠**: 줌

## 봇 채팅 (AI 대화)

다른 유저(봇)들이 서로 이름을 부르며 대화하고 플레이어의 채팅에 대답합니다.

- claude.ai에서 게임을 열면 Claude가 실제 게임 상황(보스 출현 시간, 사냥터, 레벨, 위치)과 봇마다 다른 성격을 보고 대화를 씁니다. 채팅을 치거나, 💬 버튼을 누르거나, 레벨업(5단위)·보스 처치·+6 이상 강화 같은 일이 생길 때만 호출합니다. 처음 한 번 허용을 묻고, 비용은 보는 사람 계정에서 나갑니다.
- 그 밖의 경우와 claude.ai 밖에서 열었을 때는 로컬 대화 엔진이 실제 게임 데이터로 주제별 대화(보스 시간, 파티, 강화, 거래, 뉴비 질문, 혈맹, 탈것)를 만들고, 같은 주제와 문장이 바로 반복되지 않게 합니다.
