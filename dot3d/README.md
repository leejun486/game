# 월하궁: 도깨비 야행 — 도트 3D 액션

조선 궁궐 마당을 배경으로 한 도트 3D 액션 게임입니다. 3D로 그린 장면을 저해상도로 렌더링하고, 외곽선을 찍은 뒤 픽셀 그대로 확대해서 도트 그래픽처럼 보이게 합니다.

> **English:** *Wolhagung: Night Parade of the Dokkaebi* is a 3D action RPG set in a Joseon-era palace. The game is fully playable in English, Japanese (日本語) and Simplified Chinese (简体中文): it follows your browser language, and you can switch any time with the 🌐 button on the title screen or under **Menu → Display → Language**.

## 출시 준비

- 버전: `src/version.js` (지금 1.1.0). 선택 화면 아래에 표시됩니다. 바뀐 점은 [CHANGELOG.md](CHANGELOG.md)에 적습니다.
- 판매용 빌드, itch.io·Steam 올리는 순서, 스토어 소개문(한·영), 시스템 요구 사항, 체크리스트는 [RELEASE.md](RELEASE.md)에 있습니다.
- 웹판 묶음: `npm run dist:web` → `release/Wolhagung-web-<버전>.zip`
- 체험판 묶음: `npm run dist:demo` → `release/Wolhagung-demo-web-<버전>.zip` (월하궁·죽림·폐사찰까지, 저승사자를 물리치면 '체험판 끝' 안내. 스토어 주소는 `src/edition.js`의 `STORE_URL`)

- 아이콘: `icon.png`(512), `favicon.png`(64)

## 실행

```bash
cd dot3d
python3 -m http.server 8080     # 또는 npm run serve
# http://localhost:8080 접속
```

`dist/game.js`는 빌드된 번들이라 `index.html`을 더블클릭해서 열어도 실행됩니다.

소스를 고친 뒤 다시 빌드하는 방법:

```bash
cd dot3d
npm install
npm run build      # src/ → dist/game.js
npm run watch      # 개발용 자동 빌드
```

### 테스트

```bash
npx playwright install chromium   # 처음 한 번 (헤드리스 브라우저)
npm test                          # 빌드한 뒤 모든 테스트
npm run test:only -- quests save  # 이름에 quests·save가 들어간 테스트만 (빌드 없이)
```

브라우저에서 게임을 띄워, 화면을 그리지 않고 게임 시간을 직접 돌리며 확인합니다(`tests/*.test.cjs`, 공용 도구는 `tests/harness.cjs`). 모든 테스트는 페이지 오류가 없고 화면 글에 번역 빠짐이 없어야 통과합니다.

| 테스트 | 확인하는 것 |
|---|---|
| `i18n` | 영어·일본어·중국어 사전이 같은 원문을 모두 덮는지, 문장 패턴의 수·순서가 같은지, 중국어 도트 글꼴에 쓴 글자가 다 있는지 |
| `boot` | 네 언어 타이틀이 뜨는지, 외부 서버 요청이 없는지(오프라인), 제목 명조체를 불러오는지 |
| `quests` | 메인 퀘스트 모든 단계에서 목표까지 자동 이동 길이 있는지, 새 방식 퀘스트 아홉 개를 끝까지 풀 수 있는지 (영어 화면) |
| `scenes` | 연출 장면 넷이 끝까지 돌고 엔딩으로 이어지는지, Esc 건너뛰기 뒤 상태 (일본어 화면) |
| `tower` | 시련탑 규칙 층 여섯·규칙 없는 층·각성 보스(20층부터)·기록과 업적 (중국어 화면) |
| `wave` | 북을 울린 밤 싸움 세 파가 자동 사냥으로 끝나는지, 멀리 떨어져 못 오는 적을 데려오는지 |
| `field` | 다른 지역에서 따라오다 경계에 걸리거나 덤불에 낀 몬스터를 치우는지, 자동 사냥이 퀘스트 몬스터부터 노리는지 |
| `menu` | 두루마리 메뉴: Esc로 열기, 칸으로 설정·지도·가방 열기, 설정 창에서 Esc로 되돌아오기, 닫기 |
| `mobile` | 휴대폰(가로·세로) 터치: 가상 스틱 이동, 공격 단추 누르고 있기, 일시정지 메뉴가 잘리지 않는지, 알림이 터치 단추에 가리지 않는지 |
| `save` | 저장 → 이어하기 → 다시 저장이 같은지, 옛 기록(46단계 시절) 옮기기, 찾기 퀘스트 도중 이어하기, 깨진 저장일 때 예비 기록 |

**자동 완주** (`npm test`와 따로, 직업마다 실제 2분쯤):

```bash
node tools/playthrough.cjs                     # 네 직업 모두, 새 게임 → 엔딩(메인 퀘스트 + 시련탑 10층)
node tools/playthrough.cjs mage --diff=hard    # 한 직업, 어려움
node tools/playthrough.cjs sword --from=46 --lv=57 --max=10   # 46단계부터 (막힌 곳 다시 보기)
node tools/playthrough.cjs --out=결과.json     # 단계별 기록 저장
```

봇이 자동 이동·자동 사냥으로 실제로 싸우며 진행하고(쓰러지면 다시 하기, 수련점·장비는 알아서), 단계마다 걸린 게임 시간·레벨·쓰러짐을 잽니다. 한 단계에 12분(`--stuck=`) 넘게 머물면 그 자리의 상태(위치, 남은 적과 거리·상태)를 남기고 건너뜁니다. 찾기·순서 퀘스트는 정답 위치를 알고 가므로 사람보다 빠르고, 대화는 바로 넘기므로 전체 시간은 사람이 하는 것보다 짧게 나옵니다.

## 직업

선택 화면에서 왼쪽 카드(또는 ← → / 1·2·3·4)로 직업을 고르면 오른쪽에 그 캐릭터가 크게 서 있고, 설명·능력치 막대(체력·공격·사거리·기동·난이도)·스킬(수련한 파생 기술 포함)·장비가 나옵니다. 카드를 눌러도 바로 시작되지 않습니다. 아래 버튼으로 시작합니다.

- **이어하기:** 저장된 진행(퀘스트, 장비, 위치)에 고른 직업으로 이어서 합니다. Enter 키도 이어하기입니다.
- **새로 시작:** 처음부터 합니다. 기록이 있으면 "모두 지워집니다" 확인창이 한 번 뜹니다.
- Delete 키로 기록을 지울 수 있습니다.

| 직업 | 체력 | J / 좌클릭 | Space (이동기) |
| --- | --- | --- | --- |
| 검객 이랑 | 120 | 발도베기 → 가로베기 → 내려찍기. 잠시 베지 않으면 칼을 칼집에 넣음 | 회피: 잔상을 남기며 짧은 무적 대시 |
| 도사 청운 | 100 | 불부적: 맞으면 터져 주변까지 불길, 3타는 세 장 부채꼴 | 축지: 몇 걸음 앞으로 순간 이동 |
| 요정 하늬 | 112 | 사격: 빠른 화살, 3타는 세 발 동시 | 구르기: 잎사귀를 흩날리며 짧은 무적 대시 |
| 창술사 한결 | 110 | 찌르기 → 찌르기 → 휘둘러 베기. 찌르기는 앞으로 길게 꿰뚫어 뒤에 선 적까지 맞힘 | 회피: 짧은 무적 대시 |

스킬은 직업마다 세 개입니다. K(우클릭) / L(Q) / I(R) 키로 씁니다.

| 직업 | K: 스킬 1 | L: 스킬 2 | I: 스킬 3 |
| --- | --- | --- | --- |
| 검객 | 검기: 관통하는 초승달 검기 | 일섬: 눈 깜짝할 새 앞으로 돌진. 칼을 칼집에 넣는 순간 지나간 길의 적이 한꺼번에 베임 | 회오리베기: 세 바퀴 돌며 주변 전체를 벰 |
| 도사 | 낙뢰: 팔괘 마법진에 빛이 모인 뒤 번개 다발이 연달아 내리치고, 전기 사슬이 적을 이음 | 화룡부: 꿈틀대며 날아가는 불뱀이 지나가는 적을 여러 번 태우고 끝에서 폭발 | 빙결진: 얼음 가시가 세 겹으로 퍼지며 적을 얼음 속에 가둠 (대왕은 면역) |
| 요정 | 바람화살: 관통하는 화살 9발을 부채꼴로 | 화살비: 조준한 곳에 화살이 비처럼 쏟아짐 | 회오리 정령: 앞으로 나아가며 주변 적을 빨아들여 계속 피해 |
| 창술사 | 용아창: 앞으로 길게 뻗는 창기가 선 위의 적을 모두 꿰뚫음 | 낙화창: 적에게 뛰어올라(무적) 내려찍어 주변을 띄움 | 천창우: 조준한 곳에 빛의 창이 하늘에서 쏟아짐 |

도사와 요정은 공격할 때 멀리 있는 적을 자동으로 조준합니다. 부적이나 화살로 북을 맞혀도 북이 울립니다.

## 자동 타겟

가까운 적을 자동으로 잡아 발밑에 붉은 원, 머리 위에 화살표로 표시합니다. 기본 공격과 모든 스킬이 그 적을 향하고, 낙뢰·화살비 같은 지점 스킬도 그 적의 위치에 떨어집니다. 더 가까운 적이 붙으면 알아서 바꾸고, Tab 키로 다음 적으로 넘길 수 있습니다.

## 성장 (레벨업)

- 도깨비를 쓰러뜨리면 경험치를 얻습니다. 대왕은 큰 경험치를 주고, 웨이브를 넘기면 보너스가 있습니다. 경험치 바는 체력 바 아래에 있습니다.
- 레벨이 오르면 최대 체력 +12, 공격력 +8%가 붙고, 체력이 모두 회복됩니다.
- 스킬 2는 Lv.3, 스킬 3은 Lv.5에 열립니다. 잠긴 칸에는 필요한 레벨이 표시됩니다.
- 레벨은 직업마다 따로 쌓이고, 도깨비도 플레이어 레벨에 맞춰 조금씩 강해집니다.
- 레벨이 오를수록 다음 레벨까지 필요한 경험치가 가파르게 늘어납니다(Lv.10 → 11은 590, Lv.30 → 31은 2,510). 메인 퀘스트를 끝까지 하면 Lv.60~75쯤 됩니다.

## 장비

몬스터가 가끔 장비를 떨어뜨립니다. 대왕은 반드시 떨어뜨립니다. 일반 몬스터의 장비 드롭은 아껴 두어서(종류별 확률의 절반, 방어구·장신구는 6~8%) 좋은 장비 하나하나가 반갑게 느껴지도록 했습니다. 등급 색의 빛기둥이 서고, 가까이 가면 빨려와 주워집니다. B 키나 화면의 `가방` 버튼으로 가방을 열고, 아이템을 누르면 착용합니다. 가방을 여는 동안 게임은 멈춥니다.

- **자동 착용:** 가방 오른쪽 위 `자동 착용` 버튼을 누르면 지금 직업이 가진 것 중 가장 좋은 것으로 한 번에 바꿉니다.
  - 무기는 공격력(고유 기술이 있으면 조금 더), 옷은 체력과 피해 감소, 방어구·장신구는 옵션 점수로 고릅니다.
  - 반지는 두 칸 모두 채우고, 이미 낀 좋은 반지는 그 칸에 그대로 둡니다.
  - 다른 직업이 끼고 있는 방어구·장신구는 가져오지 않습니다.
  - 이미 가장 좋은 장비를 끼고 있으면 그렇다고 알려 줍니다.

- **무기 (직업 전용, 5등급):** 착용하면 캐릭터가 든 무기의 모양이 바뀝니다. 칼날 색과 길이, 빛나는 칼(뽑으면 고유한 빛과 반짝이), 지팡이 구슬과 장식, 활의 색과 크기가 달라지고 공격력 +15~75%가 붙습니다.
  - 검객: 수련용 환도 → 강철 환도 → 청강 월광검 → 자운 비도 → 흑룡도
  - 도사: 복숭아나무 → 청동 → 월장석 → 뇌전 → 화룡 지팡이
  - 요정: 버들 활 → 물소뿔 각궁 → 바람결 활 → 서리 활 → 월궁
  - 창술사: 수련용 장창 → 강철 장창 → 청룡 언월창 → 자운 낭아창 → 적룡 장창 (등급이 오를수록 창날이 커지고 날개 달린 날·빛나는 상모가 붙음)
- **옷 (모든 직업 공용, 5등급):** 착용하면 옷 색이 바뀌고 체력과 피해 감소가 붙습니다.
  - 평상복 → 청룡 무관복 → 자운 비단옷 → 백호 전포(어깨받이) → 흑월 갑주(큰 어깨받이·가슴판)
  - 무늬와 장식이 있는 옷도 있습니다. 옷감에 무늬가 들어가고, 망토·띠 같은 장식은 달리면 뒤로 나부낍니다.

| 옷 | 등급 | 모습 |
| --- | --- | --- |
| 색동 저고리 | 고급 | 무지개 색동 소매, 허리 뒤로 늘어진 고름 띠 |
| 벚꽃 한복 | 희귀 | 분홍 바탕에 벚꽃 무늬, 꽃 비녀와 떨잠, 고름 띠 |
| 구름학 창의 | 희귀 | 흰 바탕에 구름무늬, 검은 망토 |
| 쪽빛 물결 무사복 | 영웅 | 쪽빛 물결무늬, 나부끼는 목도리, 금테 팔찌 |
| 홍매 궁중예복 | 영웅 | 붉은 바탕에 매화 가지, 가슴의 흉배, 금 화관, 고름 띠 |
| 흑매 자객복 | 영웅 | 검은 바탕에 붉은 매화, 붉은 목도리, 팔찌 |
| 월하 선녀옷 | 전설 | 연보라 바탕에 별빛, 등 뒤로 둥글게 떠 있는 빛나는 피백, 화관, 꽃 비녀 |
| 청룡 곤룡포 | 전설 | 초록 바탕에 금빛 용 원무늬, 흉배, 붉은 망토, 화관 |

같은 등급의 옷은 그중 하나가 무작위로 떨어집니다.
- 이미 가진 장비를 또 주우면 경험치로 바뀝니다.

### 방어구·장신구 (장갑 · 각반 · 허리띠 · 반지 두 개)

무기·갑옷 말고도 장비 칸이 다섯 개 더 있습니다. 장갑, 각반, 허리띠, 반지 두 개입니다. 몬스터가 가끔 떨어뜨리고(필드 몬스터 약 16%), 보스는 두세 개를 높은 등급으로 떨어뜨립니다.

- **무작위 옵션:** 주울 때마다 옵션이 무작위로 붙습니다. 등급이 높을수록 옵션이 많습니다(일반 1개 ~ 전설 4개). 전설 등급에는 보스 장비 같은 고유 효과(도깨비 벼락, 여우구슬 흡혈 등)가 하나 더 붙습니다. 몬스터 레벨과 회차가 높을수록 수치가 큽니다.
- **옵션 종류:** 공격력, 최대 체력, 받는 피해 감소, 치명타 확률, 치명타 피해, 이동 속도, 스킬 재사용 감소, 흡혈, 경험치, 초당 체력 회복
- **종류별 기본 옵션:** 장갑은 치명타 확률, 각반은 이동 속도나 체력, 허리띠는 체력이 꼭 붙고, 반지는 공격력·치명타 피해·재사용 감소·흡혈 중 하나가 붙습니다.
- **비교:** 가방에서 아이템을 누르면 옵션이 나오고, 지금 낀 것과 무엇이 오르고(▲ 초록) 내리는지(▼ 빨강) 나란히 보여 줍니다. 지금 것보다 좋은 장비에는 목록에 ▲ 표시가 붙고, 주울 때도 알려 줍니다.
- **모습:** 장갑을 끼면 손과 손목 토시, 각반을 입으면 바지와 신발, 허리띠를 매면 띠 색이 바뀝니다.
- **분해:** 필요 없는 장비는 분해해서 경험치로 바꿉니다. `일반·고급 모두 분해` 버튼으로 한 번에 정리할 수 있습니다. 가방은 40칸이고, 가득 차면 새로 주운 장비는 바로 분해됩니다.
- 가방 왼쪽에 모든 능력치(치명타, 흡혈, 이동 속도 등)와 장비 일곱 칸이 나옵니다. 장비는 직업마다 따로 끼지만 가방은 같이 씁니다.
- **외형 (가방 → 외형 탭):** 능력치는 그대로 두고 겉모습만 바꿉니다. 직업마다 따로 기억합니다.
  - 겉옷 모양: 가진 옷 중 하나의 모양(무늬·장식·뿔·여우 귀 포함)을 입은 옷 대신 보여 줍니다.
  - 무기 모양: 가진 같은 직업 무기 중 하나의 모양.
  - 염색 14가지: 기본 여섯(먹빛, 쪽빛, 진달래, 송홧빛, 비취, 소색)과 업적으로 열리는 여덟(구미호 주홍, 용궁 청옥, 눈꽃, 저승 먹보라, 금빛 전설, 달빛 은, 새벽빛, 붉은 달). 옷의 바탕·포인트·테두리·바지 색이 바뀌고 무늬는 그대로입니다.
  - 머리색 일곱 가지(은발·백발·금발·홍발은 업적으로), 방어구 색(장갑·바지·띠) 보이기/숨기기.
- 너무 세지지 않게 한계가 있습니다: 받는 피해 감소 70%(갑옷 포함), 치명타 확률 60%, 재사용 감소 40%, 이동 속도 40%, 흡혈 10%.

### 보스 전용 장비

보스 전용 장비(붉은 `보스` 등급)는 **보스만 떨어뜨리고, 확률로만** 나옵니다. 보스를 쓰러뜨릴 때마다 무기와 옷을 따로 굴립니다.

- **무기:** 12% 확률. 지금 직업용 무기 중 아직 없는 것이 먼저 나오고, 이미 있으면 다른 직업용이 나옵니다.
- **옷:** 22% 확률.
- **회차 보너스:** 회차마다 두 확률이 2%씩 오르며, 최대 +10%입니다.
- **다시 도전:** 무기가 나오지 않으면 지역의 북·방울·범종·징·풀무·봉화·용고·물레방아·얼음 북·향로·난장 북·갯마을 징·천둥 북을 다시 울려 보스에게 도전하면 됩니다.

장비마다 고유 효과가 있고, 옷을 입으면 보스를 닮은 장식이 캐릭터에 붙습니다. 아직 얻지 못한 보스 장비는 가방에 어느 보스에게서 나오는지 표시됩니다.

| F2 / F3 | 스크린샷 모드: 화면 글자 숨기기 / 지금 화면을 PNG로 저장 |
| G | 그래픽 모드 바꾸기 (고화질 ↔ 도트) |
| M | 음악 켜기/끄기 |

터치 기기에서는 왼쪽 화면을 드래그하면 가상 조이스틱이 나오고, 오른쪽에 버튼이 나옵니다.

### 게임패드

엑스박스·플레이스테이션 패드 같은 표준 게임패드를 연결하면 바로 쓸 수 있습니다.

| 버튼 | 동작 |
| --- | --- |
| 왼쪽 스틱 | 이동 |
| A / ✕ | 기본 공격, 대화 넘기기 |
| B / ○ | 피하기 |
| X / □ | 기술 1 |
| Y / △ | 기술 2 |
| RB / R1 | 기술 3 |
| RT / R2 | 고유 기술 |
| LB / L1 | 대화·조사 |
| LT / L2 | 타겟 변경 |
| Back | 가방 |
| Start | 일시정지 |
| 십자키 ↑ / ↓ / ← / → | 자동 이동 / 자동 사냥 / 기술 수련 / 큰 지도 |

메뉴(일시정지·가방·기술 창·지도)에서는 십자키나 스틱으로 화면에 보이는 위아래·좌우 칸을 따라 고르고 A로 누르며, B로 닫습니다. LB/RB로 탭을 넘기고, 슬라이더는 좌우로 조절합니다. 선택 화면에서는 좌우로 직업을 고르고, A로 이어하기, X로 새로 시작, Y로 난이도를 바꿉니다. 패드를 쓰는 동안에는 화면의 조작 안내가 A·B·X·Y 버튼 그림으로 바뀝니다(스팀 덱 1280×800 확인).

## 처음 하는 사람을 위한 안내

- **튜토리얼:** 새로 시작하면 프롤로그 뒤에 화면 아래 카드가 나와 이동 → 공격(3번) → 피하기 → 기술 → 자동 이동을 차례로 직접 해 보게 합니다.
  - 해낸 순간 다음 단계로 넘어갑니다. 카드의 `건너뛰기`로 넘길 수 있습니다.
  - 키보드, 터치, 게임패드에 맞춰 문구가 바뀌고, 바꾼 키 배치도 반영합니다.
  - 메뉴 → 조작 · 키 바꾸기의 `튜토리얼 다시 하기`로 다시 볼 수 있습니다.
- **도움말:** 처음 겪는 순간에 한 번씩 짧은 카드가 뜹니다. 첫 장비, 첫 수련점, 첫 각인 단계, 첫 보스, 처음 쓰러졌을 때(완벽한 회피 안내), 첫 사냥 임무(자동 사냥 안내)입니다. 메뉴 → 화면 → 도움말에서 끌 수 있습니다.
- **난이도:** 선택 화면의 `난이도`(패드 Y로 바꿈) 또는 메뉴 → 화면에서 언제든 바꿉니다. 저장 파일마다 따로 기억합니다.

  남쪽 지역으로 갈수록 세집니다. 표의 `A→B`는 첫 지역(월하궁) → 마지막 지역(백설 고원·시련탑) 값이고, 가운데 지역에서 빨리 오릅니다(지역 진행도의 제곱근). 우두머리는 몬스터 배율에 한 번 더 곱합니다.

  | 난이도 | 몬스터 체력 | 받는 피해 | 우두머리 체력 | 우두머리 피해 | 경험치 | 장비 드롭 |
  |---|---|---|---|---|---|---|
  | 쉬움 | 75% | 55→70% | ×1→1.6 | ×1→1.2 | 100% | 100% |
  | 보통 | 100% | 100→180% | ×1.3→3.3 | ×1→2.1 | 100% | 100% |
  | 어려움 | 130% | 120→200% | ×1.5→3 | ×1.05→1.9 | 125% | 140% |

  값은 자동 완주 봇(`tools/playthrough.cjs`)으로 맞췄습니다. 보통: 네 직업 모두 엔딩까지 쓰러짐 0~2번, 우두머리전 최저 체력이 대개 20~80%. 예전 값(배율 1)에서는 어려움에서도 원거리 직업이 한 번도 쓰러지지 않았고 우두머리가 10~40초 만에 쓰러졌습니다.

- **초반 난이도:** 첫 회차의 궁궐·죽림에서는 적이 20% 덜 아프게 때립니다(두 번째 회차부터는 그대로). 도사의 기본 체력은 100입니다.
- **직업 균형:** 레벨 20, Ⅴ단계 기준으로 자동 사냥 60초 동안의 초당 피해(단일 대상·여럿)를 재서 맞췄습니다. 도사는 몸이 약한 대신 위력 ×1.2, 요정은 ×0.92입니다. 자동 사냥은 기술마다 닿는 거리가 달라서, 검기, 일섬, 창기, 낙화창, 천창우는 붙지 않고 그 거리에서 바로 씁니다.
- **효과음:** 창술사는 찌르기, 창기, 도약, 내려찍기, 떨어지는 창, 회선창 소리를 따로 씁니다(`tools/audio/sfx.py`). `python3 sfx.py 이름…`처럼 이름을 주면 그 소리만 새로 만들고 나머지 파일은 건드리지 않습니다.

## 두루마리 메뉴

게임 중 **Esc**(게임패드 Start, 터치 기기는 왼쪽 `메뉴` 버튼)를 누르면 시간이 멈추고 오른쪽에서 **두루마리 메뉴**가 펼쳐집니다. 위아래 나무 축과 왼쪽 단청 띠가 있는 먹빛 두루마리입니다.

- **맨 위:** 달거울이 모은 조각 수만큼 차올라 있고, 지금 직업·레벨·지역·시련탑 최고 층이 나옵니다.
- **칸 (도트 그림 + 붉은 낙관에 단축키):**
  - 몸과 짐: 가방(B), 기술 수련(T), 외형
  - 여정: 지도·일지(V), 오늘의 목표(진행 수), 업적(Y), 요괴 도감
  - 도움: 자동 사냥(H, 켜져 있으면 초록 테), 자동 이동(F), 낮/밤(N), 음악(M)
  - 설정: 소리, 화면, 조작, 저장 파일, 선택 화면으로
- 새 장비·수련점이 있으면 칸에 붉은 점이 뜹니다. 설정 칸에서 연 창은 Esc를 누르면 다시 두루마리로 돌아오고, 두루마리에서 Esc를 한 번 더 누르면 닫힙니다.

## 일시정지 · 설정

두루마리의 설정 칸이나 **P** 키로 설정 창을 엽니다. 선택 화면에서는 오른쪽 아래 `설정 · 저장 파일` 버튼으로 엽니다. 설정은 진행 기록과 따로 저장됩니다.

- **소리:** 전체 · 배경음악 · 효과음 · 환경음 음량, 음악 켜기·끄기
- **화면:**
  - 언어 (한국어 / English / 日本語 / 简体中文): 바꾸면 저장 후 새로고침합니다. 처음에는 브라우저 언어를 따릅니다. 선택 화면 오른쪽 아래 🌐 버튼은 누를 때마다 다음 언어로 바뀝니다.
  - 그래픽 모드 (고화질 / 도트)
  - 화질 높음 · 보통 · 낮음: 낮음은 해상도를 줄이고 AO, 계단 현상 제거, 그림자 해상도를 낮춰 저사양 기기에서 부드럽게 돌아갑니다.
  - 화면 흔들림 (보통 · 약하게 · 끔)
  - 데미지 숫자 보이기 · 숨기기
  - 외곽선 (도트 모드)
- **조작 · 키 바꾸기:**
  - 기본 공격, 피하기, 기술 1~3, 고유 기술, 대화, 가방, 기술 수련, 자동 이동, 자동 사냥의 키를 바꿀 수 있습니다. 버튼을 누른 뒤 원하는 키를 누르면 됩니다.
  - 이동(WASD·방향키)은 고정입니다. 원래 키도 함께 동작합니다. `기본 키로 되돌리기`로 초기화합니다.
- **저장 파일:**
  - **내보내기**는 지금 기록을 `월하궁-저장-날짜.json` 파일로 내려받습니다. **불러오기**는 그 파일로 기록을 덮어씁니다. 다른 기기·브라우저로 옮기거나 백업할 때 씁니다.
  - 자동 저장 때 5분마다 예비 기록이 하나 더 남습니다. `5분 전 예비 기록으로 되돌리기`로 복구할 수 있습니다.
- **선택 화면으로:** 저장한 뒤 처음 화면으로 돌아갑니다.

## 데스크톱판 (Windows · macOS · Linux)

`desktop/` 폴더에 Electron 포장이 있습니다. 인터넷 없이 실행됩니다(글꼴·음원 모두 포함).

```bash
cd dot3d && npm run build          # 웹 버전 먼저 빌드
cd desktop
npm install
npm start                          # 창으로 바로 실행
npm run dist:win                   # release/Wolhagung-1.1.0-win-x64.zip (Windows)
npm run dist:linux                 # AppImage (Linux)
npm run dist:mac                   # dmg (macOS에서 빌드)
```

- **실행 방식:** 게임 파일을 `app://` 주소로 열어 웹판과 똑같이 동작합니다.
- **전체 화면:** F11 또는 Alt+Enter
- **저장:** 브라우저 저장소와 함께 **사용자 폴더의 `save.json` 파일**에도 저장됩니다. 둘 중 더 최근 것을 불러옵니다. 쓰다가 꺼져도 깨지지 않게 임시 파일에 쓴 뒤 바꿔치기합니다.
  - Windows: `%APPDATA%\Wolhagung\save.json`
  - macOS: `~/Library/Application Support/Wolhagung/save.json`
  - Linux: `~/.config/Wolhagung/save.json`
- **Steam 출시 전 할 일:** Steamworks SDK 연동(업적·클라우드 저장, steamworks.js 등), 코드 서명, 아이콘을 넣어야 합니다.

## 글꼴

UI 글꼴 갈무리11(SIL 오픈 폰트 라이선스, `fonts/OFL.md`)을 게임 안에 포함해서 인터넷 없이도 나옵니다. 중국어(간체) 화면은 Fusion Pixel 12px(SIL 오픈 폰트 라이선스, `fonts/FusionPixel-OFL.txt`)에서 쓰는 글자만 뽑아 넣었습니다. 제목·배너용 명조체 Noto Serif KR/JP/SC 900(OFL)도 게임에 쓰는 글자만 뽑아 `fonts/serif-kr|jp|sc.woff2`로 넣어 두어서 인터넷 없이도 같은 모양으로 나옵니다(합쳐 약 450KB). 글이 바뀌어 새 글자가 생기면 `python3 tools/i18n/serif_font.py`로 다시 만듭니다.

## 자동 저장

진행 상황(직업별 레벨·경험치·착용 장비, 가방, 회차, 퇴치 수, 최고 연속 베기, 임무 단계)과 설정(음악, 외곽선, 확대, 낮/밤)이 브라우저에 자동으로 저장됩니다. 15초마다, 웨이브를 넘길 때, 승리했을 때, 탭을 닫거나 숨길 때 저장하고, 저장될 때 오른쪽 아래에 `◆ 자동 저장됨`이 잠깐 표시됩니다. 다음에 열면 타이틀 화면에 이어하기 정보가 나옵니다. 타이틀 화면에서 Delete 키를 누르면 기록을 지웁니다. 저장이 깨졌으면(저장 도중 꺼짐 등) 5분마다 남기는 예비 기록으로 이어집니다. 싸우는 도중에 저장된 경우에는 북을 울리기 전 상태에서 이어집니다.

## 오픈월드

### 완벽한 회피

공격이 닿기 직전에 피하면(피하기·축지·구르기 직후 0.35초 안에 공격을 흘려보내면) **완벽한 회피**가 됩니다. 원 경고 공격, 돌진, 구슬 모두 해당합니다.
- **느린 시간:** 0.9초 동안 적과 적의 투사체가 4배 느려집니다.
- **쿨타임 감소:** 피하기 대기시간이 바로 끝나고, 기술 대기시간 1.5초, 고유 기술 대기시간 3초가 줄어듭니다.
- **반격:** 2.5초 안에 맞히는 다음 한 방은 반드시 치명타이고 피해가 40% 더 들어갑니다.

### 지역 기믹
- **물안개 늪:** 얕은 물웅덩이에 들어가면 걸음이 62%로 느려집니다. 물귀신과 이무기는 오히려 빨라지고, 나무 다리 위는 괜찮습니다. 물안개가 낮게 깔립니다.

- **청류 계곡:** 북서쪽 폭포에서 시냇물이 졸졸 흘러 골짜기를 가로지릅니다. 물살이 하류로 흘러가고 기슭엔 물거품이 입니다. 냇물에 들어가면 느려지고, 나무다리와 징검돌 위는 괜찮습니다. 낮엔 민들레 씨앗과 나비, 밤엔 반딧불이 날고, 시냇물 소리와 매미 소리가 들립니다.
- **백설 고원:** 무릎까지 눈이 쌓인 고원입니다. 눈 쌓인 소나무와 눈더미, 얼어붙은 못, 지붕에 눈이 쌓인 버려진 초가 마을이 있고 눈보라가 비스듬히 몰아칩니다.
- **왕릉 고분:** 해 질 녘 마른 풀밭. 홍살문에서 참도(돌길)를 따라 정자각을 지나면 언덕 위 큰 봉분이 있고, 둘레에 무인석·문인석·석양이 섰습니다. 작은 고분 위로 보랏빛 넋불이 맴돕니다.
- **도깨비 밤장터:** 천막 친 난전이 늘어서고 붉고 푸른 등롱이 줄줄이 걸렸습니다. 한가운데 윷판 멍석과 푸른 도깨비불 모닥불, 장승 한 쌍이 어귀를 지킵니다.
- **남해 갯벌 마을:** 북쪽은 초가·덕장·돌담이 있는 바닷가 마을, 남쪽은 끝없는 갯벌입니다. 갯벌의 물웅덩이에선 느려지고 인면어는 빨라집니다. 널다리 위는 괜찮습니다.
- **천상 선계:** 구름 바닥과 구름 더미, 옥돌 길, 복숭아나무, 금빛 정자, 떠다니는 별빛. 무지개를 건너 들어옵니다.
- **동해 용궁:** 바다 밑이라 물방울이 떠오르고 빛 알갱이가 떠다닙니다. 산호와 거대한 조개 사이로 길을 찾아야 합니다.
- **불가사리 협곡:** 용암 강은 돌다리로만 건널 수 있습니다. 바닥의 분화구는 6~9초마다 붉게 달아올랐다가(경고 원) 불기둥을 뿜어, 근처의 플레이어와 몬스터를 모두 다치게 하고 불을 붙입니다. 적을 분화구 위로 유인하면 유리합니다.

## 저승 시련탑 (엔드게임)

불가사리를 물리치면 협곡 대장간 옆의 **저승 문**이 열립니다. 문 앞에서 E를 누르면 허공에 뜬 시련탑으로 들어갑니다.

- **층 구성:** 층마다 적 무리가 몰려옵니다. 층이 오를수록 적이 많아지고 강해지며(층수 = 적 레벨), 지역 몬스터 종류가 차례로 섞여 들어옵니다.
- **정예:** 3층부터 나옵니다. 금빛 기운을 두르고, 체력 2.6배·피해 1.4배·경험치 3배입니다.
- **보스 층:** 5층마다 지역 보스가 나옵니다(두억시니 → 구미호 → 저승사자 → 이무기 → 불가사리 → 백호 → 용왕 → 왕지네 → 동장군 순서로 돌아감). 10층마다는 시련탑에만 나오는 **염라대왕**이 나옵니다.
  - 염라대왕은 사라졌다가 등 뒤에서 나타납니다.
  - 붉은 벼락 판결을 세 번 연달아 내리고, 검은 초승달을 날립니다.
- **층 돌파:**
  - 층을 돌파하면 경험치와 장비를 받습니다. 처음 돌파한 층은 1.5배이고 장비도 하나 더 줍니다. 5층마다 세트 조각도 나옵니다.
  - 가운데에 다음 층 문이 열리고, 남쪽 홍살문으로 언제든 나갈 수 있습니다. 새 층에 오르면 체력이 30% 회복됩니다.
- **특수 규칙 층:** 6층부터, 보스 층과 3의 배수 층을 뺀 층(7·8·11·13·14·16·17·19층…)에 규칙이 붙습니다. 같은 층은 늘 같은 규칙이고, 여섯 규칙이 차례로 돌아갑니다. 규칙 층은 경험치 1.5배에 장비를 하나 더 줍니다.

  | 규칙 | 내용 |
  |---|---|
  | 질풍의 층 | 적 이동 속도 1.35배 |
  | 정예의 층 | 적 수는 절반, 모두 정예 |
  | 어둠의 층 | 내 주변만 밝고 나머지는 어둠 |
  | 불바다 | 3.5초마다 내 주변에 불기둥 예고 원 다섯 개 |
  | 떼의 층 | 적 수 두 배(최대 24), 체력 60% |
  | 유리 몸 | 주는 피해·받는 피해 모두 1.6배 |
- **각성 보스:** 시련탑 20층부터의 보스 층과, 이미 평정한 지역의 북·방울 등을 다시 울려 부른 보스는 `각성`한 채로 나옵니다(첫 판의 보스는 각성하지 않음). 검보랏빛 기운을 두르고 체력 1.6배·피해 1.25배, 조금 더 크고 빠르며 공격 준비·빈틈이 짧습니다. 쓰러뜨리면 영웅 등급 이상 장비를 하나 더 떨어뜨립니다.
- **이어서 도전:** 최고 기록은 저장됩니다. 다음에 들어가면 5층 단위로 이어서 도전합니다(예: 12층까지 갔으면 11층부터). 쓰러지면 협곡의 저승 문 앞으로 돌아옵니다.

## 이야기 · 엔딩

- **프롤로그:** 새로 시작하면 달거울이 열네 조각으로 깨지는 이야기가 나옵니다. 클릭·Space로 넘기고, Esc로 건너뜁니다.
- **달거울 조각:** 도깨비 대왕, 구미호, 저승사자, 이무기, 불가사리, 백호, 용왕, 왕지네, 동장군, 어둑시니, 독각귀, 장산범, 뇌공을 처음 물리칠 때마다 조각을 하나씩 되찾고 짧은 이야기가 나옵니다.
- **엔딩:** 메인 퀘스트를 마친 뒤 시련탑 10층의 염라대왕을 처음 쓰러뜨리면 마지막 조각을 받습니다. 에필로그, 기록(레벨, 회차, 퇴치 수, 최고 연속, 시련탑, 플레이 시간), 크레딧이 이어집니다.
- 엔딩 뒤에도 그대로 이어서 플레이합니다(시련탑, 회차, 현상수배). 선택 화면의 이어하기 정보에 `달거울 복원`이 붙습니다.
- 이야기 글은 `src/story.js`에 모여 있습니다(크레딧의 제작자 이름도 여기서 바꿉니다).

## 언어 (한국어 / English / 日本語 / 简体中文)

- 게임 코드는 한국어 원문 그대로 두고, 화면에 나가는 글자를 `src/i18n.js`가 번역합니다.
  - 버튼, 알림, 패널 등 화면(DOM)에 글자가 생기면 자동으로 번역합니다.
  - 한 글자씩 찍히는 대화와 이야기는 넘겨받을 때 번역합니다.
- 사전은 `src/lang/`에 있습니다.
  - `en_data.js`: 직업, 기술, 각인, 이야기, 지역
  - `en_items.js`: 아이템, 장비, 퀘스트
  - `en_ui.js`: 화면 글자, 그리고 숫자·이름이 끼어드는 문장의 패턴
  - 일본어 `ja_*.js`, 중국어(간체) `zh_*.js`: 같은 구성. 패턴은 `ja_pats.js`·`zh_pats.js`.
- 일본어·중국어 사전은 손으로 고치지 않고 `tools/i18n/<언어>_<부분>.txt`(영어 사전의 줄 번호마다 `줄|번역1 ‖ 번역2 …`)를 고친 뒤 `node tools/i18n/build_lang.cjs ja items`처럼 다시 만듭니다. 줄마다 항목 수가 영어 사전과 다르면 만들지 않고 알려 줍니다.
- 글꼴: 한국어·영어·일본어는 갈무리11(일본어 가나·한자 포함). 중국어(간체)는 같은 계열 도트 글꼴인 Fusion Pixel 12px(OFL)에서 번역에 쓰인 글자만 뽑은 `fonts/fusion-zh.woff2`(약 40KB)를 씁니다. 중국어 번역을 고쳐 새 글자가 생기면 `python3 tools/i18n/zh_font.py <npm pack @vp-tw/cjk-web-fonts-fusion-pixel-font를 푼 package 폴더>`로 다시 만듭니다.
- 장비 이름처럼 여러 낱말을 조합한 글은 낱말별로 번역해 이어 붙입니다(예: `푸른 은 가락지` → `Verdant Silver Ring`, 일본어·중국어는 띄어쓰기 없이 `青い銀の指輪`).
- 번역을 못 찾은 글은 그대로 한국어로 나오고, 브라우저 콘솔의 `window.__i18nMissing`에 모입니다. 새 글을 넣었다면 여기를 보고 사전에 추가하면 됩니다.

### 자동 이동 · 자동 사냥

- **자동 이동:** 오른쪽 위 임무 창을 누르거나 F 키를 누르면, 길찾기 지도를 따라 지금 퀘스트의 목표까지 알아서 걸어갑니다. 도착하면 대화, 북·방울 울리기, 석등 켜기까지 대신 합니다. 처치·수집 퀘스트는 목표 지역에 닿으면 멈추고 알려 줍니다(자동 이동은 이동만 하고, 가는 길에 싸우지 않습니다). 싸우려면 자동 사냥을 켜면 됩니다. 석등 퀘스트는 다음 석등으로 차례로 이동합니다.
- **자동 사냥:** `자동 사냥` 버튼이나 H 키로 켭니다. 가까운 적을 찾아 직업에 맞는 거리(검객은 붙어서, 도사·요정은 떨어져서)를 지키며 싸웁니다. 재사용 대기가 끝난 스킬은 적이 하나뿐이어도 바로 쓰고(기본 공격 동작이 끝나는 대로 끼워 넣음), 스킬은 마우스가 아니라 싸우는 적을 겨냥합니다. 떨어진 장비도 주워 갑니다.
- 직접 이동 키를 누르면 자동 이동이 멈춥니다. 대화창이 열려 있는 동안에는 잠시 쉽니다.

## 파생 기술 (기술 수련, 5단계 · 각인)

스킬마다 두 갈래 중 하나를 골라 Ⅰ~Ⅴ단계까지 다섯 번 수련합니다. T 키나 화면의 `기술` 버튼으로 창을 엽니다.

- 레벨이 오를 때마다 **수련점** 1점을 얻고, 한 단계에 1점을 씁니다. 단계마다 필요한 레벨이 있습니다 (K: Lv.4·7·10·13·16, L: Lv.6·9·12·15·18, I: Lv.8·11·14·17·20).
- Ⅰ단계에서 갈래를 고르면 기술이 바뀝니다.
- Ⅱ~Ⅴ단계는 숫자만 오르는 대신 **각인**을 하나씩 골라 기술의 효과를 바꿉니다. 수련한 단계의 각인은 수련점 없이 언제든 바꿀 수 있습니다. 단계마다 위력이 8%씩 오르고, 재사용 대기가 4%씩 줄어드는 것은 덤입니다.
- 갈래도 언제든 다른 쪽으로 바꿀 수 있고, 쌓은 단계와 각인은 그대로 유지됩니다.

## 게임 흐름

1. 왼쪽 북 옆의 **수문장**에게 말을 겁니다.
2. **큰 북**을 울리면(E 키 또는 검으로 북을 베기) 밤이 되고 도깨비가 몰려옵니다.
3. 제1파(꼬마 도깨비) → 제2파(붉은 도깨비, 도깨비불) → 제3파(도깨비 대왕 두억시니) 순서로 나옵니다.
4. 이기면 날이 밝습니다. 이후는 퀘스트를 따라 남문 밖 죽림, 설원 폐사찰, 물안개 늪, 불가사리 협곡, 단풍 산성, 동해 용궁, 청류 계곡, 백설 고원, 왕릉 고분, 도깨비 밤장터, 남해 갯벌 마을, 천상 선계로 내려가며 사냥하고, 각 지역의 우두머리를 쓰러뜨립니다.

전투 요소:

- 도깨비는 공격 직전에 붉게 깜빡입니다. 회피나 베기로 끊을 수 있습니다.
- 도깨비불의 푸른 불덩이는 검으로 베면 튕겨낼 수 있습니다.
- 대왕은 바닥에 붉은 경고 원을 그린 뒤 내려찍고, 멀리 있으면 뛰어올라 덮칩니다. 체력이 60%, 30% 아래로 내려가면 졸개를 부릅니다.
- 타격하면 히트스톱, 화면 흔들림, 치명타, 연속 베기 카운터가 나옵니다.

### 환경음
- **궁궐 낮:** 바람, 참새 지저귐
- **밤:** 귀뚜라미, 소쩍새
- **죽림:** 댓잎 서걱임, 대나무 부딪는 소리
- **폐사찰:** 찬바람, 풍경, 까마귀
- **늪:** 개구리 울음, 물방울, 찰랑이는 물
- **협곡:** 부글거리는 용암, 톡톡 터지는 기포, 먼 땅울림
- **산성:** 마른 잎 바스락, 먼 까마귀, 깃발 펄럭임
- **왕릉:** 무덤 사이 바람, 부엉이, 풀벌레, 웅얼거리는 넋
- **밤장터:** 웅성거림, 엽전 짤랑, 모닥불 타닥
- **갯마을:** 먼 파도, 갯벌 뽀글거림, 갈매기
- **선계:** 높은 바람, 멀리 우르릉 천둥, 학 울음
- **용궁:** 웅웅거리는 물결, 떠오르는 물방울
- **계곡:** 졸졸 흐르는 시냇물(작은 물방울 소리 수백 개를 겹침), 매미 소리, 먼 새소리
- **고원:** 휘몰아치는 바람, 눈을 쓸고 가는 소리, 풍경
- **시련탑:** 허공의 바람, 멀리서 웅얼거리는 망자

### 효과음
42가지 효과음이 있습니다.
- **여러 벌을 번갈아 씀:** 베기·타격·치명타처럼 자주 나는 소리는 2~5벌을 번갈아 냅니다. 높낮이도 ±3.5% 흔들어 똑같은 소리가 반복되지 않게 합니다.
- **대화:** 글자가 나올 때마다 가야금 음이 평조로 퉁겨집니다.
- **레벨업:** 가야금을 훑어 올리고 방울이 울립니다.
- **웨이브 시작:** 나발 소리가 납니다.
- **승리:** 징, 가야금, 꽹과리가 함께 울립니다.

### 음원 만들기·바꾸기
음원은 실제 녹음이 아니라 `tools/audio/`의 파이썬 코드로 합성해 만듭니다.
- **악기 소리 (`synth.py`):** 가야금·거문고는 부분음 합성과 농현·꺾기로, 대금은 숨소리와 청 울림으로 만듭니다. 해금·피리·태평소는 포먼트 필터로, 장구·북·꽹과리·징·범종은 막과 금속의 울림을 흉내 내 만듭니다.
- **배경음악 (`compose.py`, `tracks.py`):** 장단 위에 A A' B A'' 형식으로 선율을 짓고, 여러 악기가 같은 가락을 저마다 꾸며 연주하게 합니다(헤테로포니). 공간 잔향을 입혀 렌더합니다.
- **효과음 (`sfx.py`)**

다시 만들려면 `pip install numpy scipy`와 `ffmpeg`가 필요하고, 그다음 `npm run audio`를 실행합니다.

실제 연주 녹음으로 바꾸려면 같은 이름의 파일(`audio/music/palace.ogg`와 `.mp3` 등)을 덮어쓰고, `audio/music/manifest.json`의 `samples`(전체 샘플 수)를 새 파일에 맞게 고칩니다.

## 그래픽: 고화질

그래픽은 **고화질** 하나입니다. 예전에는 선택 화면에서 도트 모드로 바꿀 수 있었지만, 일부 기기에서 도트 모드로 바꾸면 게임이 시작되지 않아 없앴습니다(예전에 도트로 저장된 설정은 열 때 지움). 무거운 기기에서는 메뉴 → 화면의 `화질`(높음·보통·낮음)로 가볍게 합니다. 아래 도트 렌더링 설명은 코드에 남아 있는 예전 모드에 대한 것입니다.

고화질 모드 (`src/pixel.js`의 HD 경로, `src/hdtex.js`):

- **해상도:** 화면 해상도 그대로 렌더하고(기기 배율 최대 1.5배, 휴대폰은 화소 수를 줄임), MSAA로 계단 현상을 없앱니다.
- **카메라:** 화각이 좁은 원근 카메라를 52° 아래로 기울여, 건물 앞면과 기단이 보이고 깊이감이 생깁니다.
- **재질:** 툰 음영 대신 부드러운 물리 기반 음영을 씁니다. 금속 장식은 은은하게 반사됩니다. 그림자는 4096 해상도의 부드러운 그림자입니다.
- **텍스처:** 박석 길, 판석, 석축, 기와, 칠한 나무, 회벽, 풀밭, 흙, 눈, 솔잎, 나무껍질, 깃발, 바닥 문양을 고해상도로 새로 그립니다. 돌 사이 줄눈과 닳은 모서리, 기와 골, 돋을새김 문양은 노멀맵으로 빛을 받습니다.
- **캐릭터:** 머리를 둥글게 다듬고, 반짝이는 눈동자와 눈썹, 입을 그렸습니다. 머리카락은 가닥과 옆머리로 나눴습니다. 도포와 치마에는 주름을 잡았고, 소매는 넓게 퍼지며 끝동이 달려 있습니다. 바지는 대님으로 묶었고, 버선코처럼 앞코가 솟은 신발을 신습니다. 검객의 도포에는 동정, 단 장식, 매듭 띠를 달았습니다.
- **캐릭터 몸놀림 (`src/character.js`):**
  - 팔꿈치: 팔을 뼈대가 있는 스킨 메시로 바꿔 팔꿈치가 자연스럽게 굽습니다. 무기를 쥔 손목은 각도를 보정해 칼끝 방향이 유지됩니다.
  - 머리카락: 끝으로 갈수록 가늘어지는 가닥(앞머리 7~9가닥, 옆머리, 궁수의 긴 뒷머리·꽁지머리)으로 만들고, 정수리를 덮는 머리 덮개를 씌웠습니다. 검객은 댕기 두 갈래와 동곳을 꽂습니다.
  - 옷감: 고화질 모드에서 평직 무늬 노멀맵을 입혀 천의 결이 빛을 받습니다.
  - 표정: 눈썹이 있는 눈이 깜박이고, 공격할 때는 눈을 가늘게 뜨고 눈썹이 내려가며, 다치면 입을 벌립니다. 볼 터치와 엄지가 있는 손을 더했습니다.
  - 2차 움직임: 스프링으로 계산해 댕기, 치마 자락, 꼬리, 장식이 달리는 속도에 맞춰 뒤로 날리고 멈추면 출렁입니다. 달릴 때 몸통이 좌우로 기울고 가슴이 반대로 틀어집니다. 서 있으면 고개를 이리저리 돌려 둘러봅니다.
  - 잔상: 피하기 잔상도 뼈대째 복제해 굽은 팔 자세가 그대로 남습니다.
- **월하궁 정원:** 연못 섬 위 육각정(두 겹 지붕과 금빛 절병통)과 붉은 무지개 다리, 단청 띠를 두른 침전과 서고, 붉은 꽃 문양을 넣은 꽃담, 밤이면 불이 켜지는 청사초롱 기둥과 석등, 매화·벚나무가 있습니다. 침전 꽃살 창호에는 밤에 불빛이 비칩니다.
- **선택 화면:** 직업 카드와 오른쪽 큰 그림을 고해상도(MSAA)로 그려서 도트가 아닌 매끈한 3D 캐릭터로 보입니다.
- **소나무:** 굽은 줄기에 가장자리가 들쭉날쭉한 납작한 솔잎층을 얹어 분재 같은 모양으로 바꿨습니다.
- **후처리:**
  - 화면 공간 AO: 모서리와 틈에 은은한 그늘
  - 블룸: 밝은 곳과 밤 등불이 번짐
  - 틸트시프트: 화면 위아래를 흐려 미니어처 느낌
  - 필믹 톤매핑과 따뜻한 색보정, 구름 그림자, 비네트

## 도트 3D 렌더링 방식 (`src/pixel.js`, 도트 모드)

1. **저해상도 렌더**: 화면을 픽셀 크기(2~6배)로 나눈 해상도로 그리고, `image-rendering: pixelated`로 확대합니다. 텍스처도 1유닛당 16텍셀로 맞춰서 화면 픽셀과 텍셀 크기가 같습니다.
2. **노멀·깊이 패스**: 같은 장면을 `MeshNormalMaterial`로 한 번 더 그립니다. 깃발이나 소나무처럼 정점이 움직이는 메시는 같은 변형을 넣은 노멀 재질을 씁니다.
3. **외곽선 합성 셰이더**: 이웃 픽셀보다 깊이가 가까우면 실루엣으로 보고 어둡게 칠하고, 노멀이 꺾이는 모서리는 한쪽만 밝게 칠합니다.
4. **카메라 텍셀 스냅**: 정사영 카메라 위치를 화면 픽셀 격자에 맞춰서, 이동할 때 도트가 지글거리지 않게 합니다. 스냅하고 남는 소수점 이동은 캔버스를 CSS로 밀어서 스크롤이 부드럽게 보이게 합니다. 그림자 카메라도 섀도맵 텍셀 단위로 스냅합니다.
5. **후처리**: 깊이로 월드 좌표를 복원해서 흐르는 구름 그림자를 디더링으로 찍습니다. 낮/밤 색보정, 비네트를 넣고 채널을 양자화합니다.

그 밖의 구성:

- `textures.js`: 박석(보로노이), 기와, 단청, 창호, 깃발 글자, 북 삼태극 같은 텍스처를 모두 캔버스에서 절차적으로 생성
- `geom.js`: 처마 곡선과 귀솟음이 있는 한옥 지붕 생성기, 정적 메시 병합(Batcher)
- `materials.js`: 4단계 툰 셰이딩, 바람 셰이더(깃발, 소나무, 밟으면 눕는 풀)
- `items.js`: 무기·옷 목록, 등급, 드롭 확률, 도트 아이콘
- `gear.js`: 장갑·각반·허리띠·반지, 무작위 옵션, 세트, 분해
- `classes.js`: 직업 설정 (검객·도사·요정의 체력, 재사용 대기시간, 버튼 이름)
- `character.js`: 2.5등신 캐릭터(검객, 도사, 요정, 수문장, 나인, 도깨비, 대왕, 강시, 원귀, 저승사자)와 네발 짐승(여우, 구미호)와 걷기·베기·회피·피격·사망을 코드로 계산하는 애니메이션
- `maps.js`, `worlds2.js`: 지역 설정(웨이브, 필드 몬스터, 조명)과 죽림·폐사찰 지형. `world.js`의 `REGIONS`가 세 지역을 한 땅에 이어 붙임
- `evolve.js`: 파생 기술 갈래와 단계
- `quests.js`: 메인 퀘스트와 현상수배
- `entities.js`: 플레이어, 몬스터 AI(돌진, 강시 뜀뛰기, 순간이동, 보스 패턴), NPC, 다가가면 날아가는 참새
- `fx.js`: 도트 파티클(정사각 포인트), 검기 호, 충격파, 지면 경고, 데미지 숫자
- `audio.js`: WebAudio로 만드는 효과음과, 평조 오음계 가야금풍 선율과 장구 장단의 배경음

외부 이미지나 사운드 파일 없이 모두 코드로 생성합니다. 사용하는 라이브러리는 Three.js 하나이고, 글꼴(갈무리11, Fusion Pixel 일부, Noto Serif 일부)은 모두 `fonts/`에 들어 있어 인터넷 연결이 필요 없습니다.
