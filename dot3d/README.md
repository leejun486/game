# 월하궁(月下宮): 도깨비 야행 — 도트 3D 액션

조선 궁궐 마당을 배경으로 한 도트 3D 액션 게임입니다. 3D로 그린 장면을 저해상도로 렌더링하고, 외곽선을 찍은 뒤 픽셀 그대로 확대해서 도트 그래픽처럼 보이게 합니다.

## 실행

```bash
cd dot3d
python3 -m http.server 8080     # 또는 npm run serve
# http://localhost:8080 접속
```

`dist/game.js`는 빌드된 번들이라 `index.html`을 더블클릭해서 열어도 실행됩니다.

소스를 고친 뒤 다시 빌드하는 방법:

```bash
cd dot3d
npm install
npm run build      # src/ → dist/game.js
npm run watch      # 개발용 자동 빌드
```

## 직업

타이틀 화면에서 ← → (또는 1·2·3) 키로 직업을 고르고 Enter로 시작합니다. 카드를 눌러도 됩니다. 고른 직업은 자동 저장됩니다.

| 직업 | 체력 | J / 좌클릭 | Space (이동기) |
| --- | --- | --- | --- |
| 검객 이랑 | 120 | 발도베기 → 가로베기 → 내려찍기. 잠시 베지 않으면 칼을 칼집에 넣음 | 회피: 잔상을 남기며 짧은 무적 대시 |
| 도사 청운 | 90 | 불부적: 맞으면 터져 주변까지 불길, 3타는 세 장 부채꼴 | 축지: 몇 걸음 앞으로 순간 이동 |
| 요정 하늬 | 100 | 사격: 빠른 화살, 3타는 세 발 동시 | 구르기: 잎사귀를 흩날리며 짧은 무적 대시 |

스킬은 직업마다 세 개입니다. K(우클릭) / L(Q) / I(R) 키로 씁니다.

| 직업 | K: 스킬 1 | L: 스킬 2 | I: 스킬 3 |
| --- | --- | --- | --- |
| 검객 | 검기: 관통하는 초승달 검기 | 일섬: 눈 깜짝할 새 앞으로 돌진. 칼을 칼집에 넣는 순간 지나간 길의 적이 한꺼번에 베임 | 회오리베기: 세 바퀴 돌며 주변 전체를 벰 |
| 도사 | 낙뢰: 팔괘 마법진에 빛이 모인 뒤 번개 다발이 연달아 내리치고, 전기 사슬이 적을 이음 | 화룡부: 꿈틀대며 날아가는 불뱀이 지나가는 적을 여러 번 태우고 끝에서 폭발 | 빙결진: 얼음 가시가 세 겹으로 퍼지며 적을 얼음 속에 가둠 (대왕은 면역) |
| 요정 | 바람화살: 관통하는 화살 9발을 부채꼴로 | 화살비: 조준한 곳에 화살이 비처럼 쏟아짐 | 회오리 정령: 앞으로 나아가며 주변 적을 빨아들여 계속 피해 |

도사와 요정은 공격할 때 멀리 있는 적을 자동으로 조준합니다. 부적이나 화살로 북을 맞혀도 북이 울립니다.

## 자동 타겟

가까운 적을 자동으로 잡아 발밑에 붉은 원, 머리 위에 화살표로 표시합니다. 기본 공격과 모든 스킬이 그 적을 향하고, 낙뢰·화살비 같은 지점 스킬도 그 적의 위치에 떨어집니다. 더 가까운 적이 붙으면 알아서 바꾸고, Tab 키로 다음 적으로 넘길 수 있습니다.

## 성장 (레벨업)

- 도깨비를 쓰러뜨리면 경험치를 얻습니다. 대왕은 큰 경험치를 주고, 웨이브를 넘기면 보너스가 있습니다. 경험치 바는 체력 바 아래에 있습니다.
- 레벨이 오르면 최대 체력 +12, 공격력 +8%가 붙고, 체력이 모두 회복됩니다.
- 스킬 2는 Lv.3, 스킬 3은 Lv.5에 열립니다. 잠긴 칸에는 필요한 레벨이 표시됩니다.
- 레벨은 직업마다 따로 쌓이고, 도깨비도 플레이어 레벨에 맞춰 조금씩 강해집니다.

## 장비

도깨비가 가끔 장비를 떨어뜨립니다. 대왕은 반드시 떨어뜨립니다. 등급 색의 빛기둥이 서고, 가까이 가면 빨려와 주워집니다. B 키나 화면의 `가방` 버튼으로 가방을 열고, 아이템을 누르면 착용합니다. 가방을 여는 동안 게임은 멈춥니다.

- **무기 (직업 전용, 5등급):** 착용하면 캐릭터가 든 무기의 모양이 바뀝니다. 칼날 색과 길이, 빛나는 칼(뽑으면 고유한 빛과 반짝이), 지팡이 구슬과 장식, 활의 색과 크기가 달라지고 공격력 +15~75%가 붙습니다.
  - 검객: 수련용 환도 → 강철 환도 → 청강 월광검 → 자운 비도 → 흑룡도
  - 도사: 복숭아나무 → 청동 → 월장석 → 뇌전 → 화룡 지팡이
  - 요정: 버들 활 → 물소뿔 각궁 → 바람결 활 → 서리 활 → 월궁
- **옷 (모든 직업 공용, 5등급):** 착용하면 옷 색이 바뀌고 체력과 피해 감소가 붙습니다.
  - 평상복 → 청룡 무관복 → 자운 비단옷 → 백호 전포(어깨받이) → 흑월 갑주(큰 어깨받이·가슴판)
- 이미 가진 장비를 또 주우면 경험치로 바뀝니다.

## 자동 저장

진행 상황(직업별 레벨·경험치·착용 장비, 가방, 회차, 퇴치 수, 최고 연속 베기, 임무 단계)과 설정(음악, 외곽선, 확대, 낮/밤)이 브라우저에 자동으로 저장됩니다. 15초마다, 웨이브를 넘길 때, 승리했을 때, 탭을 닫거나 숨길 때 저장하고, 저장될 때 오른쪽 아래에 `◆ 자동 저장됨`이 잠깐 표시됩니다. 다음에 열면 타이틀 화면에 이어하기 정보가 나옵니다. 타이틀 화면에서 Delete 키를 누르면 기록을 지웁니다. 싸우는 도중에 저장된 경우에는 북을 울리기 전 상태에서 이어집니다.

## 게임 흐름

1. 왼쪽 북 옆의 **수문장**에게 말을 겁니다.
2. **큰 북**을 울리면(E 키 또는 검으로 북을 베기) 밤이 되고 도깨비가 몰려옵니다.
3. 제1파(꼬마 도깨비) → 제2파(붉은 도깨비, 도깨비불) → 제3파(도깨비 대왕 두억시니) 순서로 나옵니다.
4. 이기면 날이 밝습니다. 북을 다시 울리면 회차가 올라가고, 도깨비가 더 많아지고 강해집니다.

전투 요소:

- 도깨비는 공격 직전에 붉게 깜빡입니다. 회피나 베기로 끊을 수 있습니다.
- 도깨비불의 푸른 불덩이는 검으로 베면 튕겨낼 수 있습니다.
- 대왕은 바닥에 붉은 경고 원을 그린 뒤 내려찍고, 멀리 있으면 뛰어올라 덮칩니다. 체력이 60%, 30% 아래로 내려가면 졸개를 부릅니다.
- 타격하면 히트스톱, 화면 흔들림, 치명타, 연속 베기 카운터가 나옵니다.

## 도트 3D 렌더링 방식 (`src/pixel.js`)

1. **저해상도 렌더**: 화면을 픽셀 크기(2~6배)로 나눈 해상도로 그리고, `image-rendering: pixelated`로 확대합니다. 텍스처도 1유닛당 16텍셀로 맞춰서 화면 픽셀과 텍셀 크기가 같습니다.
2. **노멀·깊이 패스**: 같은 장면을 `MeshNormalMaterial`로 한 번 더 그립니다. 깃발이나 소나무처럼 정점이 움직이는 메시는 같은 변형을 넣은 노멀 재질을 씁니다.
3. **외곽선 합성 셰이더**: 이웃 픽셀보다 깊이가 가까우면 실루엣으로 보고 어둡게 칠하고, 노멀이 꺾이는 모서리는 한쪽만 밝게 칠합니다.
4. **카메라 텍셀 스냅**: 정사영 카메라 위치를 화면 픽셀 격자에 맞춰서, 이동할 때 도트가 지글거리지 않게 합니다. 스냅하고 남는 소수점 이동은 캔버스를 CSS로 밀어서 스크롤이 부드럽게 보이게 합니다. 그림자 카메라도 섀도맵 텍셀 단위로 스냅합니다.
5. **후처리**: 깊이로 월드 좌표를 복원해서 흐르는 구름 그림자를 디더링으로 찍습니다. 낮/밤 색보정, 비네트를 넣고 채널을 양자화합니다.

그 밖의 구성:

- `textures.js`: 박석(보로노이), 기와, 단청, 창호, 깃발 글자, 북 삼태극 같은 텍스처를 모두 캔버스에서 절차적으로 생성
- `geom.js`: 처마 곡선과 귀솟음이 있는 한옥 지붕 생성기, 정적 메시 병합(Batcher)
- `materials.js`: 4단계 툰 셰이딩, 바람 셰이더(깃발, 소나무, 밟으면 눕는 풀)
- `items.js`: 무기·옷 목록, 등급, 드롭 확률, 도트 아이콘
- `classes.js`: 직업 설정 (검객·도사·요정의 체력, 재사용 대기시간, 버튼 이름)
- `character.js`: 2.5등신 캐릭터(검객, 도사, 요정, 수문장, 나인, 도깨비, 대왕)와 걷기·베기·회피·피격·사망을 코드로 계산하는 애니메이션
- `entities.js`: 플레이어, 도깨비 AI, 도깨비불, 보스, NPC, 다가가면 날아가는 참새
- `fx.js`: 도트 파티클(정사각 포인트), 검기 호, 충격파, 지면 경고, 데미지 숫자
- `audio.js`: WebAudio로 만드는 효과음과, 평조 오음계 가야금풍 선율과 장구 장단의 배경음

외부 이미지나 사운드 파일 없이 모두 코드로 생성합니다. 사용하는 라이브러리는 Three.js 하나이고, UI 폰트는 Galmuri를 CDN에서 불러옵니다.
