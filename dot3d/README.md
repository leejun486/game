# 월하궁: 도깨비 야행 — 도트 3D 액션

조선 궁궐 마당을 배경으로 한 도트 3D 액션 게임입니다. 3D로 그린 장면을 저해상도로 렌더링하고, 외곽선을 찍은 뒤 픽셀 그대로 확대해서 도트 그래픽처럼 보이게 합니다.

## 실행

```bash
cd dot3d
python3 -m http.server 8080     # 또는 npm run serve
# http://localhost:8080 접속
```

`dist/game.js`는 빌드된 번들이라 `index.html`을 더블클릭해서 열어도 실행됩니다.

소스를 고친 뒤 다시 빌드하는 방법:

```bash
cd dot3d
npm install
npm run build      # src/ → dist/game.js
npm run watch      # 개발용 자동 빌드
```

## 직업

선택 화면에서 왼쪽 카드(또는 ← → / 1·2·3)로 직업을 고르면 오른쪽에 그 캐릭터가 크게 서 있고, 설명·능력치 막대(체력·공격·사거리·기동·난이도)·스킬(수련한 파생 기술 포함)·장비가 나옵니다. 카드를 눌러도 바로 시작되지 않습니다. 아래 버튼으로 시작합니다.

- **이어하기:** 저장된 진행(퀘스트, 장비, 위치)에 고른 직업으로 이어서 합니다. Enter 키도 이어하기입니다.
- **새로 시작:** 처음부터 합니다. 기록이 있으면 "모두 지워집니다" 확인창이 한 번 뜹니다.
- Delete 키로 기록을 지울 수 있습니다.

| 직업 | 체력 | J / 좌클릭 | Space (이동기) |
| --- | --- | --- | --- |
| 검객 이랑 | 120 | 발도베기 → 가로베기 → 내려찍기. 잠시 베지 않으면 칼을 칼집에 넣음 | 회피: 잔상을 남기며 짧은 무적 대시 |
| 도사 청운 | 90 | 불부적: 맞으면 터져 주변까지 불길, 3타는 세 장 부채꼴 | 축지: 몇 걸음 앞으로 순간 이동 |
| 요정 하늬 | 100 | 사격: 빠른 화살, 3타는 세 발 동시 | 구르기: 잎사귀를 흩날리며 짧은 무적 대시 |

스킬은 직업마다 세 개입니다. K(우클릭) / L(Q) / I(R) 키로 씁니다.

| 직업 | K: 스킬 1 | L: 스킬 2 | I: 스킬 3 |
| --- | --- | --- | --- |
| 검객 | 검기: 관통하는 초승달 검기 | 일섬: 눈 깜짝할 새 앞으로 돌진. 칼을 칼집에 넣는 순간 지나간 길의 적이 한꺼번에 베임 | 회오리베기: 세 바퀴 돌며 주변 전체를 벰 |
| 도사 | 낙뢰: 팔괘 마법진에 빛이 모인 뒤 번개 다발이 연달아 내리치고, 전기 사슬이 적을 이음 | 화룡부: 꿈틀대며 날아가는 불뱀이 지나가는 적을 여러 번 태우고 끝에서 폭발 | 빙결진: 얼음 가시가 세 겹으로 퍼지며 적을 얼음 속에 가둠 (대왕은 면역) |
| 요정 | 바람화살: 관통하는 화살 9발을 부채꼴로 | 화살비: 조준한 곳에 화살이 비처럼 쏟아짐 | 회오리 정령: 앞으로 나아가며 주변 적을 빨아들여 계속 피해 |

도사와 요정은 공격할 때 멀리 있는 적을 자동으로 조준합니다. 부적이나 화살로 북을 맞혀도 북이 울립니다.

## 자동 타겟

가까운 적을 자동으로 잡아 발밑에 붉은 원, 머리 위에 화살표로 표시합니다. 기본 공격과 모든 스킬이 그 적을 향하고, 낙뢰·화살비 같은 지점 스킬도 그 적의 위치에 떨어집니다. 더 가까운 적이 붙으면 알아서 바꾸고, Tab 키로 다음 적으로 넘길 수 있습니다.

## 성장 (레벨업)

- 도깨비를 쓰러뜨리면 경험치를 얻습니다. 대왕은 큰 경험치를 주고, 웨이브를 넘기면 보너스가 있습니다. 경험치 바는 체력 바 아래에 있습니다.
- 레벨이 오르면 최대 체력 +12, 공격력 +8%가 붙고, 체력이 모두 회복됩니다.
- 스킬 2는 Lv.3, 스킬 3은 Lv.5에 열립니다. 잠긴 칸에는 필요한 레벨이 표시됩니다.
- 레벨은 직업마다 따로 쌓이고, 도깨비도 플레이어 레벨에 맞춰 조금씩 강해집니다.

## 장비

도깨비가 가끔 장비를 떨어뜨립니다. 대왕은 반드시 떨어뜨립니다. 등급 색의 빛기둥이 서고, 가까이 가면 빨려와 주워집니다. B 키나 화면의 `가방` 버튼으로 가방을 열고, 아이템을 누르면 착용합니다. 가방을 여는 동안 게임은 멈춥니다.

- **무기 (직업 전용, 5등급):** 착용하면 캐릭터가 든 무기의 모양이 바뀝니다. 칼날 색과 길이, 빛나는 칼(뽑으면 고유한 빛과 반짝이), 지팡이 구슬과 장식, 활의 색과 크기가 달라지고 공격력 +15~75%가 붙습니다.
  - 검객: 수련용 환도 → 강철 환도 → 청강 월광검 → 자운 비도 → 흑룡도
  - 도사: 복숭아나무 → 청동 → 월장석 → 뇌전 → 화룡 지팡이
  - 요정: 버들 활 → 물소뿔 각궁 → 바람결 활 → 서리 활 → 월궁
- **옷 (모든 직업 공용, 5등급):** 착용하면 옷 색이 바뀌고 체력과 피해 감소가 붙습니다.
  - 평상복 → 청룡 무관복 → 자운 비단옷 → 백호 전포(어깨받이) → 흑월 갑주(큰 어깨받이·가슴판)
  - 무늬와 장식이 있는 옷도 있습니다. 옷감에 무늬가 들어가고, 망토·띠 같은 장식은 달리면 뒤로 나부낍니다.

| 옷 | 등급 | 모습 |
| --- | --- | --- |
| 색동 저고리 | 고급 | 무지개 색동 소매, 허리 뒤로 늘어진 고름 띠 |
| 벚꽃 한복 | 희귀 | 분홍 바탕에 벚꽃 무늬, 꽃 비녀와 떨잠, 고름 띠 |
| 구름학 창의 | 희귀 | 흰 바탕에 구름무늬, 검은 망토 |
| 쪽빛 물결 무사복 | 영웅 | 쪽빛 물결무늬, 나부끼는 목도리, 금테 팔찌 |
| 홍매 궁중예복 | 영웅 | 붉은 바탕에 매화 가지, 가슴의 흉배, 금 화관, 고름 띠 |
| 흑매 자객복 | 영웅 | 검은 바탕에 붉은 매화, 붉은 목도리, 팔찌 |
| 월하 선녀옷 | 전설 | 연보라 바탕에 별빛, 등 뒤로 둥글게 떠 있는 빛나는 피백, 화관, 꽃 비녀 |
| 청룡 곤룡포 | 전설 | 초록 바탕에 금빛 용 원무늬, 흉배, 붉은 망토, 화관 |

같은 등급의 옷은 그중 하나가 무작위로 떨어집니다.
- 이미 가진 장비를 또 주우면 경험치로 바뀝니다.

### 방어구·장신구 (장갑 · 각반 · 허리띠 · 반지 두 개)

무기·갑옷 말고도 장비 칸이 다섯 개 더 있습니다. 장갑, 각반, 허리띠, 반지 두 개입니다. 몬스터가 가끔 떨어뜨리고(필드 몬스터 약 16%), 보스는 두세 개를 높은 등급으로 떨어뜨립니다.

- **무작위 옵션:** 주울 때마다 옵션이 무작위로 붙습니다. 등급이 높을수록 옵션이 많습니다(일반 1개 ~ 전설 4개). 전설 등급에는 보스 장비 같은 고유 효과(도깨비 벼락, 여우구슬 흡혈 등)가 하나 더 붙습니다. 몬스터 레벨과 회차가 높을수록 수치가 큽니다.
- **옵션 종류:** 공격력, 최대 체력, 받는 피해 감소, 치명타 확률, 치명타 피해, 이동 속도, 스킬 재사용 감소, 흡혈, 경험치, 초당 체력 회복
- **종류별 기본 옵션:** 장갑은 치명타 확률, 각반은 이동 속도나 체력, 허리띠는 체력이 꼭 붙고, 반지는 공격력·치명타 피해·재사용 감소·흡혈 중 하나가 붙습니다.
- **비교:** 가방에서 아이템을 누르면 옵션이 나오고, 지금 낀 것과 무엇이 오르고(▲ 초록) 내리는지(▼ 빨강) 나란히 보여 줍니다. 지금 것보다 좋은 장비에는 목록에 ▲ 표시가 붙고, 주울 때도 알려 줍니다.
- **모습:** 장갑을 끼면 손과 손목 토시, 각반을 입으면 바지와 신발, 허리띠를 매면 띠 색이 바뀝니다.
- **분해:** 필요 없는 장비는 분해해서 경험치로 바꿉니다. `일반·고급 모두 분해` 버튼으로 한 번에 정리할 수 있습니다. 가방은 40칸이고, 가득 차면 새로 주운 장비는 바로 분해됩니다.
- 가방 왼쪽에 모든 능력치(치명타, 흡혈, 이동 속도 등)와 장비 일곱 칸이 나옵니다. 장비는 직업마다 따로 끼지만 가방은 같이 씁니다.
- 너무 세지지 않게 한계가 있습니다: 받는 피해 감소 70%(갑옷 포함), 치명타 확률 60%, 재사용 감소 40%, 이동 속도 40%, 흡혈 10%.

### 세트 아이템

장갑·각반·허리띠·반지 네 부위로 된 세트가 네 가지 있습니다. 세트 조각은 초록색 이름으로 떨어지고(일반 몬스터 장비 드롭의 약 9%, 보스는 40%), 영웅 등급 옵션이 붙습니다. 같은 세트를 2개, 4개 끼면 세트 효과가 켜집니다. 가방에서 몇 개를 끼고 있는지와 켜진 효과를 볼 수 있습니다.

| 세트 | 나오는 곳 | 2세트 | 4세트 |
| --- | --- | --- | --- |
| 도깨비 대왕의 차림 | 월하궁 도깨비·대왕 | 공격력 +10% | 치명타 피해 +30%, 도깨비 벼락 |
| 구미호의 홀림 | 죽림 여우·여우불·구미호 | 이동 속도 +8%, 치명타 +5% | 재사용 -10%, 여우구슬 흡혈 |
| 저승사자의 명부 | 폐사찰 강시·원귀·저승사자 | 받는 피해 -8% | 혼 거두기 + 저승 심판 |
| 월하 선인의 유품 | 세 보스 | 경험치 +15%, 초당 회복 +2 | 재사용 -15%, 공격력 +15% |

### 보스 전용 장비

보스를 쓰러뜨리면 일반 장비와 함께 그 보스의 전용 장비(붉은 `보스` 등급)를 하나 더 떨어뜨립니다. 아직 없는 것부터 나오며, 순서는 지금 직업의 무기 → 옷 → 다른 직업 무기입니다. 장비마다 고유 효과가 있고, 옷을 입으면 보스를 닮은 장식이 캐릭터에 붙습니다. 아직 얻지 못한 보스 장비는 가방에 어느 보스에게서 나오는지 표시됩니다.

| 보스 | 무기 (검객 / 도사 / 요정) | 무기 효과 | 옷 | 옷 효과 · 모습 |
| --- | --- | --- | --- | --- |
| 두억시니 | 두억시니 참마도 / 금방망이 / 뿔활 (공격 +85%) | 도깨비 벼락: 맞힐 때 20% 확률로 벼락이 떨어져 주변 적에게 충격파 | 두억시니 뿔갑주 (체력 +110, 피해 -20%) | 체력이 40% 아래면 공격력 +35% · 금빛 뿔과 이마 구슬 |
| 천년 구미호 | 구미호 여우검 / 여우구슬 지팡이 / 구미 꼬리활 (+90%) | 여우구슬: 준 피해의 6%만큼 체력 회복 | 구미호 털옷 (체력 +95, 피해 -16%) | 이동 속도 +15%, 이동기 대기시간 -30% · 여우 귀와 흔들리는 꼬리 셋 |
| 저승사자 | 저승 명부검 / 명부 지팡이 / 망령 활 (+100%) | 저승 심판: 체력 35% 아래인 적에게 피해 +60% | 저승사자 도포 (체력 +120, 피해 -22%) | 적을 쓰러뜨릴 때마다 최대 체력 4% 회복 · 검은 갓과 보랏빛 갓끈 |

무기와 옷의 효과는 함께 적용됩니다. 예를 들어 여우검과 저승 도포를 같이 입으면 흡혈과 처치 회복이 모두 켜집니다.

## 자동 저장

진행 상황(직업별 레벨·경험치·착용 장비, 가방, 회차, 퇴치 수, 최고 연속 베기, 임무 단계)과 설정(음악, 외곽선, 확대, 낮/밤)이 브라우저에 자동으로 저장됩니다. 15초마다, 웨이브를 넘길 때, 승리했을 때, 탭을 닫거나 숨길 때 저장하고, 저장될 때 오른쪽 아래에 `◆ 자동 저장됨`이 잠깐 표시됩니다. 다음에 열면 타이틀 화면에 이어하기 정보가 나옵니다. 타이틀 화면에서 Delete 키를 누르면 기록을 지웁니다. 싸우는 도중에 저장된 경우에는 북을 울리기 전 상태에서 이어집니다.

## 오픈월드

세 지역이 하나의 넓은 땅으로 이어져 있습니다. 화면 전환 없이 걸어서 오갑니다.

```
월하궁 (궁궐 마당) ── 남문 ──▶ 죽림 (대숲 오솔길, 서낭당) ──▶ 설원 폐사찰 (눈 덮인 절터, 석탑)
     북쪽                                                              남쪽
```

- 다른 지역에 들어서면 지역 이름이 뜨고, 하늘빛·햇빛·날리는 것(꽃잎·잎사귀·눈)이 천천히 그 지역의 색으로 바뀝니다. 오른쪽 위 지역 이름과 임무도 바뀝니다.
- 지역 사이는 자연스럽게 이어집니다. 궁궐 남문 밖은 장승과 소나무가 선 풀밭 어귀로 대숲이 시작되고, 대숲 남쪽 끝은 눈이 조금씩 내려앉아 설원이 되며, 폐사찰은 담장과 일주문으로 둘러싸여 있습니다. 바닥 재질이 바뀌는 곳은 도트 디더링으로 섞입니다.
- 궁궐 남문과 폐사찰 일주문(금줄)은 퀘스트를 진행해야 열립니다.
- 각 지역에는 밤 싸움을 부르는 물건이 있습니다. 월하궁은 큰 북, 죽림은 서낭당 방울, 폐사찰은 종각의 범종입니다. 퀘스트에서 그 차례가 되면 울릴 수 있고, 울리면 그 지역의 몬스터가 세 파로 몰려오고 마지막 파에 우두머리가 나옵니다. 이미 평정한 곳은 E 키로 다시 울려 회차를 올릴 수 있습니다(싸우다 실수로 울리지 않게 칼질로는 안 울림).
- **필드 몬스터:** 죽림과 폐사찰에서는 몬스터 무리가 곳곳에 생겨나 어슬렁거립니다(한 지역에 최대 6마리). 가까이 가거나 공격하면 머리 위에 `!`가 뜨고 주변 무리와 함께 달려들고, 멀리 달아나면 포기합니다. 쓰러뜨리면 경험치와 장비를 줍니다. 궁궐은 안전한 마을입니다.
- 마지막으로 서 있던 위치가 저장되어 그 자리에서 이어집니다.

| 지역 | 부르는 것 | 몬스터 | 우두머리 |
| --- | --- | --- | --- |
| 월하궁 | 큰 북 | 꼬마 도깨비, 붉은 도깨비, 도깨비불 | 도깨비 대왕 두억시니: 경고 원 뒤 내려찍기, 도약, 졸개 소환 |
| 죽림 | 서낭당 방울 | 여우: 몸을 낮췄다가 덮쳐 무는 돌진 / 여우불: 주황 불덩이를 쏨 | 천년 구미호: 아홉 꼬리. 바닥에 경고선을 긋고 돌진하거나, 여우불 일곱 개를 부채꼴로 뿌림 |
| 설원 폐사찰 | 종각의 범종 | 강시: 두 팔을 뻗고 콩콩 뛰어옴 / 원귀: 반투명한 소복 귀신, 순간이동하며 원혼 구슬을 쏨 | 저승사자: 사라졌다가 등 뒤에 나타나 내려베기, 사방으로 퍼지는 저승 파동 |

남쪽 지역일수록 몬스터가 강합니다. 지역을 평정할 때마다 회차가 올라갑니다.

## 퀘스트

이야기는 퀘스트를 따라 진행됩니다. 오른쪽 위 임무 창에 지금 할 일과 진행도(예: 여우 3/6)가 나옵니다. 할 일이 있는 사람·물건 위에는 노란 느낌표가 뜨고, 목표가 멀리 있으면 발밑의 노란 화살표가 방향을 가리킵니다. 단계를 마치면 경험치와 장비를 받습니다.

| 순서 | 퀘스트 | 할 일 | 보상 |
| --- | --- | --- | --- |
| 1 | 수문장을 찾아서 | 수문장 박돌쇠와 이야기 | |
| 2 | 도깨비 야행 | 큰 북을 울려 도깨비 세 파를 물리침 | 경험치 |
| 3 | 남문이 열리다 | 수문장에게 보고 → 남문이 열림 | 색동 저고리 |
| 4 | 죽림 어귀 | 남문 밖 약초꾼 분이와 이야기 | |
| 5 | 여우 사냥 | 숲을 돌아다니는 여우 6마리 | 경험치 |
| 6 | 여우불 구슬 | 여우불을 쓰러뜨려 여우구슬 4개 | 희귀 무기 |
| 7 | 서낭당의 방울 | 방울을 울려 천년 구미호를 물리침 | 경험치 |
| 8 | 대숲 너머 | 일주문 앞 떠돌이 도사 청허와 이야기 → 금줄이 걷힘 | |
| 9 | 떠도는 망자 | 강시 5, 원귀 3 | 경험치 |
| 10 | 꺼진 석등 | 폐사찰 석등 네 곳에 불 밝히기 (E) | 쪽빛 물결 무사복 |
| 11 | 저승의 문 | 범종을 울려 저승사자를 물리침 | 경험치 |
| 12 | 귀환 | 수문장에게 돌아가 보고 | 영웅 무기 |

메인 퀘스트를 마치면 수문장이 **현상수배**(지역 몬스터 처치, 반복)를 줍니다. 완료하면 경험치와 상급 장비를 받습니다.

### 자동 이동 · 자동 사냥

- **자동 이동:** 오른쪽 위 임무 창을 누르거나 F 키를 누르면, 길찾기 지도를 따라 지금 퀘스트의 목표까지 알아서 걸어갑니다. 도착하면 대화, 북·방울 울리기, 석등 켜기까지 대신 합니다. 처치·수집 퀘스트는 목표 지역에 닿으면 자동 사냥으로 이어집니다. 석등 퀘스트는 다음 석등으로 차례로 이동합니다.
- **자동 사냥:** `자동 사냥` 버튼이나 H 키로 켭니다. 가까운 적을 찾아 직업에 맞는 거리(검객은 붙어서, 도사·요정은 떨어져서)를 지키며 기본 공격과 스킬을 씁니다. 떨어진 장비도 주워 갑니다.
- 직접 이동 키를 누르면 자동 이동이 멈춥니다. 대화창이 열려 있는 동안에는 잠시 쉽니다.

## 파생 기술 (기술 수련, 5단계)

스킬마다 두 갈래 중 하나를 골라 Ⅰ~Ⅴ단계까지 다섯 번 수련합니다. T 키나 화면의 `기술` 버튼으로 창을 엽니다.

- 레벨이 오를 때마다 **수련점** 1점을 얻고, 한 단계에 1점을 씁니다. 단계마다 필요한 레벨이 있습니다 (K: Lv.4·7·10·13·16, L: Lv.6·9·12·15·18, I: Lv.8·11·14·17·20).
- Ⅰ단계에서 갈래를 고르면 기술이 바뀝니다. Ⅱ·Ⅳ단계는 피해가 오르고 재사용 대기가 줄고, Ⅲ단계는 강화, Ⅴ단계는 각성입니다. 단계는 버튼 이름에 Ⅰ~Ⅴ로 표시됩니다.
- 갈래는 언제든 다른 쪽으로 바꿀 수 있고, 쌓은 단계는 그대로 유지됩니다.

| 직업 | 스킬 | 갈래 | Ⅲ 강화 | Ⅴ 각성 |
| --- | --- | --- | --- | --- |
| 검객 | 검기 | 삼연 검기 | 다섯 줄기 | 금빛 일곱 줄기 |

## 게임 흐름

1. 왼쪽 북 옆의 **수문장**에게 말을 겁니다.
2. **큰 북**을 울리면(E 키 또는 검으로 북을 베기) 밤이 되고 도깨비가 몰려옵니다.
3. 제1파(꼬마 도깨비) → 제2파(붉은 도깨비, 도깨비불) → 제3파(도깨비 대왕 두억시니) 순서로 나옵니다.
4. 이기면 날이 밝습니다. 이후는 퀘스트를 따라 남문 밖 죽림, 설원 폐사찰로 내려가며 사냥하고, 각 지역의 우두머리를 쓰러뜨립니다.

전투 요소:

- 도깨비는 공격 직전에 붉게 깜빡입니다. 회피나 베기로 끊을 수 있습니다.
- 도깨비불의 푸른 불덩이는 검으로 베면 튕겨낼 수 있습니다.
- 대왕은 바닥에 붉은 경고 원을 그린 뒤 내려찍고, 멀리 있으면 뛰어올라 덮칩니다. 체력이 60%, 30% 아래로 내려가면 졸개를 부릅니다.
- 타격하면 히트스톱, 화면 흔들림, 치명타, 연속 베기 카운터가 나옵니다.

## 그래픽 모드: 고화질 / 도트

기본은 **고화질**입니다. 선택 화면 왼쪽 아래 `그래픽` 버튼이나 G 키로 도트 모드와 바꿀 수 있습니다. 바꾸면 저장 후 새로고침해서 적용합니다.

고화질 모드 (`src/pixel.js`의 HD 경로, `src/hdtex.js`):

- **해상도:** 화면 해상도 그대로 렌더하고(기기 배율 최대 1.5배, 휴대폰은 화소 수를 줄임), MSAA로 계단 현상을 없앱니다.
- **카메라:** 화각이 좁은 원근 카메라를 52° 아래로 기울여, 전각 앞면과 축대가 보이고 깊이감이 생깁니다.
- **재질:** 툰 음영 대신 부드러운 물리 기반 음영을 씁니다. 금속 장식은 은은하게 반사됩니다. 그림자는 4096 해상도의 부드러운 그림자입니다.
- **텍스처:** 마당 박석, 월대 판석, 어도, 석축, 기와, 칠한 나무, 회벽, 풀밭, 흙, 눈, 솔잎, 나무껍질, 깃발, 바닥 문양을 고해상도로 새로 그립니다. 돌 사이 줄눈과 닳은 모서리, 기와 골, 돋을새김 문양은 노멀맵으로 빛을 받습니다.
- **캐릭터:** 머리를 둥글게 다듬고, 반짝이는 눈동자와 눈썹, 입을 그렸습니다. 머리카락은 가닥과 옆머리로 나눴습니다. 도포와 치마에는 주름을 잡았고, 소매는 넓게 퍼지며 끝동이 달려 있습니다. 바지는 대님으로 묶었고, 버선코처럼 앞코가 솟은 신발을 신습니다. 검객의 도포에는 동정, 단 장식, 매듭 띠를 달았습니다.
- **전각:** 단청 문양(머리초 연꽃)을 기둥머리와 창방에 둘렀고, 꽃살 창호에는 밤에 불빛이 비칩니다. 기둥머리(주두)와 겹겹의 공포(첨차, 소로, 쇠서)를 쌓았고, 처마 밑에는 서까래가 보입니다. 답도에는 구름 무늬를 돋을새김했습니다.
- **소나무:** 굽은 줄기에 가장자리가 들쭉날쭉한 납작한 솔잎층을 얹어 분재 같은 모양으로 바꿨습니다.
- **후처리:**
  - 화면 공간 AO: 모서리와 틈에 은은한 그늘
  - 블룸: 밝은 곳과 밤 등불이 번짐
  - 틸트시프트: 화면 위아래를 흐려 미니어처 느낌
  - 필믹 톤매핑과 따뜻한 색보정, 구름 그림자, 비네트

## 도트 3D 렌더링 방식 (`src/pixel.js`, 도트 모드)

1. **저해상도 렌더**: 화면을 픽셀 크기(2~6배)로 나눈 해상도로 그리고, `image-rendering: pixelated`로 확대합니다. 텍스처도 1유닛당 16텍셀로 맞춰서 화면 픽셀과 텍셀 크기가 같습니다.
2. **노멀·깊이 패스**: 같은 장면을 `MeshNormalMaterial`로 한 번 더 그립니다. 깃발이나 소나무처럼 정점이 움직이는 메시는 같은 변형을 넣은 노멀 재질을 씁니다.
3. **외곽선 합성 셰이더**: 이웃 픽셀보다 깊이가 가까우면 실루엣으로 보고 어둡게 칠하고, 노멀이 꺾이는 모서리는 한쪽만 밝게 칠합니다.
4. **카메라 텍셀 스냅**: 정사영 카메라 위치를 화면 픽셀 격자에 맞춰서, 이동할 때 도트가 지글거리지 않게 합니다. 스냅하고 남는 소수점 이동은 캔버스를 CSS로 밀어서 스크롤이 부드럽게 보이게 합니다. 그림자 카메라도 섀도맵 텍셀 단위로 스냅합니다.
5. **후처리**: 깊이로 월드 좌표를 복원해서 흐르는 구름 그림자를 디더링으로 찍습니다. 낮/밤 색보정, 비네트를 넣고 채널을 양자화합니다.

그 밖의 구성:

- `textures.js`: 박석(보로노이), 기와, 단청, 창호, 깃발 글자, 북 삼태극 같은 텍스처를 모두 캔버스에서 절차적으로 생성
- `geom.js`: 처마 곡선과 귀솟음이 있는 한옥 지붕 생성기, 정적 메시 병합(Batcher)
- `materials.js`: 4단계 툰 셰이딩, 바람 셰이더(깃발, 소나무, 밟으면 눕는 풀)
- `items.js`: 무기·옷 목록, 등급, 드롭 확률, 도트 아이콘
- `gear.js`: 장갑·각반·허리띠·반지, 무작위 옵션, 세트, 분해
- `classes.js`: 직업 설정 (검객·도사·요정의 체력, 재사용 대기시간, 버튼 이름)
- `character.js`: 2.5등신 캐릭터(검객, 도사, 요정, 수문장, 나인, 도깨비, 대왕, 강시, 원귀, 저승사자)와 네발 짐승(여우, 구미호)와 걷기·베기·회피·피격·사망을 코드로 계산하는 애니메이션
- `maps.js`, `worlds2.js`: 지역 설정(웨이브, 필드 몬스터, 조명)과 죽림·폐사찰 지형. `world.js`의 `REGIONS`가 세 지역을 한 땅에 이어 붙임
- `evolve.js`: 파생 기술 갈래와 단계
- `quests.js`: 메인 퀘스트와 현상수배
- `entities.js`: 플레이어, 몬스터 AI(돌진, 강시 뜀뛰기, 순간이동, 보스 패턴), NPC, 다가가면 날아가는 참새
- `fx.js`: 도트 파티클(정사각 포인트), 검기 호, 충격파, 지면 경고, 데미지 숫자
- `audio.js`: WebAudio로 만드는 효과음과, 평조 오음계 가야금풍 선율과 장구 장단의 배경음

외부 이미지나 사운드 파일 없이 모두 코드로 생성합니다. 사용하는 라이브러리는 Three.js 하나이고, UI 폰트는 Galmuri를 CDN에서 불러옵니다.
